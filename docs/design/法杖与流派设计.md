# 金币法杖系统 + 攻击形态扩展设计（草案 v0.1，待确认）

> 阶段 0 产物。依据：用户需求 + 魔法工艺（法杖/法术容器）+ 雨中冒险（道具形态化）+ Game Balance Concepts。
> 目标：让金币有明确消耗出口、Build 从"纯数值"升级为"攻击形态差异"。

## 1. 金币法杖系统

### 1.1 法杖定义（wands.json 数据表）

法杖 = 法术网格的**容器基底**：装备后决定网格的释放形态与基础词条。数据驱动：

```json
{
  "id": "fire_staff",
  "name": "烈焰法杖",
  "rarity": "common",
  "price": 120,
  "shape": "burst",            // 攻击形态（见 1.3）
  "base_damage_mult": 1.0,
  "attack_speed_mult": 1.0,
  "element_bonus": {"fire": 0.25},
  "affixes": [{"id": "atk", "min": 5, "max": 15}]  // 随机词条池
}
```

### 1.2 获取方式（用户指定：打 Boss 后用金币购买）

- 每关 Boss 击杀 → 出现**法杖商店**（结算前弹层，3 把随机法杖 + 刷新/离开）
- 价格按稀有度：普通 120 / 稀有 260 / 传说 520（数值待平衡）
- 已购法杖替换当前网格基底；旧法杖不保留（肉鸽单局内换装，可"买新丢旧"）
- 金币另可购买：恢复药（仅 Boss 战后商店有售，加强"回血稀缺"）

### 1.3 攻击形态（shape）——核心差异化

| shape | 表现 | 数据 |
|---|---|---|
| burst 爆发 | 命中爆炸溅射 | aoe ×2，单发高伤 |
| rapid 连珠 | 快速三连 | shots 3，damage ×0.8，cd ×0.7 |
| orbit 环绕 | 法术环绕自身 | orbit 模式，持续输出 |
| scatter 散射 | 扇形齐射 | shots 5，spread 24° |
| summon 召唤 | 召唤系强化 | 召唤物 +2，召唤伤害 +50% |
| frost 冰霜 | 冻结强化 | 冻结概率 +30%，冰伤 +40% |
| homing 追踪 | 全弹追踪 | homing 全开 |

### 1.4 词条系统

- 每把法杖 1-2 条随机词条：攻/速/范围/元素/暴击
- 商店 UI：卡片展示形态图标 + 词条 + 价格，金币不足置灰

## 2. 攻击形态扩展（Build 非纯数值）

### 2.1 移速流派（3.1）

- **联动**：每 +10% 移速 → +5% 攻速（balance: `speed_to_attack_speed = 0.5`），移速 Build 有攻击收益
- 新道具：疾风靴（移速 +15%/层，攻速联动生效）、踏风护符（闪避后 2s 内攻速 +40%）
- 成型：移速 150%+ → 攻速等效 +75%，配攻速道具乘法叠加

### 2.2 防御模块 / 反甲（3.2）

- 反甲改造：现有 `thorn_armor`（免伤概率）保留 + **新增反弹**：受击时将所受伤害的 40%（每层 +15%）反弹给攻击者（近战敌人直接受伤，远程反弹弹幕消失）
- 新道具：磐石护甲（减伤 +8%/层，上限 50%）、荆棘王冠（受击反弹 + 免伤 10%）
- 联动：防御 Build 与吸血、回血道具形成"站撸流"

### 2.3 技能流 / 技能范围（3.3）

- 范围道具已作用于 AoE ✓（area_crystal）；扩展：
  - 范围词条同时放大技能命中半径与弹幕体积（视觉反馈）
  - 新道具：法阵刻印（技能范围 +20%/层）、回响宝珠（技能 15% 概率二次释放，伤害 ×0.5）
- 技能槽（梦之形式）：Demo 先做"范围强化 + 回响"，完整技能槽 M4 排期

## 3. 回血途径收紧（用户指定）

- 击杀治疗掉落：概率 0.14 → **0.02**（几乎不靠掉落回血）
- 过关回血 40%：**移除**；改为 **Boss 战后回 30% + 商店可购恢复药**（每次商店限购 1 个，回 25%）
- 保留：吸血牙（需构筑投入）、守护护盾（概率免疫）
- 目的：血量成为稀缺资源，防御/吸血 Build 价值上升，Boss 战更有压力

## 4. 数据表与验收

- 新表：`data/wands.json`（6-8 把法杖）、items 新增 5-6 件形态道具、balance 加联动参数
- 测试：test_curves.py 扩展（法杖价格/词条合法性、移速联动公式、反弹计算）；hud_layout_test 扩展（商店 UI 布局）
- 自动通关需重验（回血收紧后难度上升，可能需回调伤害曲线）
