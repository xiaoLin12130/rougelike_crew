# 特效柔化报告

> 日期：2026-08-13 ｜ 范围：怪物死亡碎屑柔化 / 屏幕震屏幅度下调 ｜ 方式：headless 实现 + 自动化测试验证 ｜ 改动文件：仅 scripts/fx/fx_manager.gd（铁律⑤）

## 1. 怪物死亡碎块柔化（问题 1）

### 1.1 问题

`_spawn_death_debris` 在怪物死亡时用 `draw_rect` 生成像素方块（普通 4-6 / 精英 8-10 / Boss 14-18）：边缘锐利、尺寸偏大（半宽 2.4-4.8px，即 4.8-9.6px 见方）、颜色为贴图主色提亮后饱和度高，与像素场景对比突兀，用户反馈"硬方块不和谐"。

### 1.2 方案（有死亡反馈，但不再突兀）

| 维度 | 旧 | 新（柔化） |
|---|---|---|
| 形状 | draw_rect 硬方块 | 抗锯齿柔边圆点（外圈柔边 + 内圈亮芯，draw_circle antialiased） |
| 尺寸 | 半宽 2.4-4.8px（×1.1/×1.3） | 半径 1.4-2.2px（×1.05/×1.2），最大仍低于旧下限 2.4 |
| 下落 | 重力 620 / 初速 90-270 | 重力 1050 / 初速 80-220（落地更快、飞散收窄） |
| 渐隐 | 尾段 45% 寿命淡出 | 尾段 70% 寿命开始线性淡出 + 起始透明度 90%（更早、更柔和） |
| 寿命 | 普通 0.3-0.5 / Boss 0.55-0.8 | 普通 0.26-0.38 / Boss 0.42-0.6（快速淡出） |
| 颜色 | 贴图主色提亮（饱和度高） | 降饱和 ×0.55 + 提亮（新增 `_soften_death_color`）；精英掺金 0.45→0.25 |

- 数量档位保持 4-6 / 8-10 / 14-18：`test_hit_feel.gd` 对碎屑数有硬断言（`_debris_count()` 按 `DeathDebris` 类计数），且铁律⑤禁止改动该测试；柔化通过形状 / 尺寸 / 寿命 / 颜色实现，视觉密度与"硬方块感"已显著降低。
- 旋转 / 自旋移除（圆形柔点无需旋转）。

## 2. 屏幕震屏幅度下调（问题 2）

### 2.1 调用点排查（`EventBus.screen_shake.emit` 共 12 处）

- `fx_manager.gd`：`SHAKE_SMALL`(3.0)、`SHAKE_PLAYER_HIT`(2.5)、暴击硬编码 2.0、爆炸 0.1s 延时 `_emit_shake`；
- `boss.gd`：12.0（死亡）/ 10.0 / 6.0 ×2 / 5.0 / 4.0；
- `enemy.gd`：6.0；`summon.gd`：4.0；
- synergies：3.0（summon / wind / thunder）、0.8（crit）。

`camera_shake.gd` 换算：`offset = randf(-1,1) * amount`，amount 由 power 在 0.15s 内线性衰减到 0 —— 实际偏移峰值 = power（px）。

### 2.2 方案（铁律：只改 fx_manager.gd，不动 camera_shake.gd 与各调用点）

- **① 常量整体下调**：`SHAKE_SMALL` 3.0→1.5、`SHAKE_PLAYER_HIT` 2.5→1.2；
- **② 入口幂衰减压缩**：新增 `static compress_shake_power(p) = p / (1 + 0.08p)`，收口在唯一入口 `_on_screen_shake`（先压缩、再过 0.25s 节流合并窗口）——等价于在 camera_shake 偏移公式加"power 越大衰减越快"，且覆盖全部 12 个调用点，无需逐个改文件；
- **③ 大震屏降幅**：Boss 死亡 12→≈6.1（达成"12→6"目标）、10→≈5.6、6→≈4.0、5→≈3.6、4→≈3.0、3→≈2.4、2→≈1.7、1.5→≈1.3、1.2→≈1.1、0.8→≈0.75。

节流 0.25s 合并窗口保持不变（仍只保留冷却期内最强一次）。

## 4. 改动清单

**唯一改动文件：`scripts/fx/fx_manager.gd`**

1. 震屏常量：`SHAKE_SMALL` 3.0→1.5、`SHAKE_PLAYER_HIT` 2.5→1.2（含柔化说明注释）；
2. 新增 `static compress_shake_power(p)`（p/(1+0.08p) 幂衰减）；
3. `_on_screen_shake` 入口先压缩再进节流；新增 `_apply_camera_shake` 助手，`_process_shake_throttle` 复用（pending 值同样已压缩）；
4. 碎屑常量：新增 `DEBRIS_SIZE_MIN/MAX`（1.4/2.2）、`DEBRIS_LIFE_MIN/MAX`（0.26/0.38）、`DEBRIS_BOSS_LIFE_MIN/MAX`（0.42/0.6）、`DEBRIS_GRAV` 620→1050；
5. `_spawn_death_debris`：尺寸改用常量、初速 90-270→80-220、精英掺金 0.45→0.25；
6. 新增 `static _soften_death_color`（HSV 降饱和 ×0.55 + 提亮），`_death_color` 落缓存前调用；
7. `DeathDebris` 内嵌类重写：`draw_rect` 硬方块 → 抗锯齿柔边圆点（外圈 + 亮芯）、`GRAV` 1050、`FADE_WINDOW` 0.7、去除旋转自旋、起始透明度 0.9、最短寿命下限 0.12s。

**新增文件（测试/文档交付物）**：`scripts/tests/test_fx_soften.gd`、`scripts/tests/test_fx_soften.tscn`、本报告 `docs/design/特效柔化报告.md`。

> 未改动：camera_shake.gd、boss.gd / enemy.gd / summon.gd / synergies 等所有 `screen_shake.emit` 调用点（由入口压缩统一降幅）。
