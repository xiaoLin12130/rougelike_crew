## 1. 拆分阈值说明

### 1.1 道具（items.json，293 条）

旧 common → 白/绿：绿（uncommon）若满足任一：
- tags 含 `mechanic:*`（机制初现，21 件）
- linear 曲线 base ≥ 0.10（如 力量徽章 +10%/层、范围水晶 +12%、生命 +25 等）
- exp_proc 曲线 base ≥ 0.15（如 灵魂石 25% 不消失、共鸣水晶 15%）
- threshold 曲线 step/threshold ≥ 0.5（如 毒液瓶、淬毒刃油、召唤之书 每 2 层 +1）
其余 → 白。

旧 rare → 蓝/金：金（epic）为人工评审清单（67 件），依据：
- 大数值/乘区：linear base ≥ 0.15、multiplicative、tradeoff、阈值 step≥0.5
- 特殊槽位：饰品 trinket、记忆 memory（余烬坠饰/霜之心/记忆-破军/记忆-疾风）
- 特殊功能：避雷针（精英优先）、静电力场（连锁跳数+1）等
- 强机制（48 件 mechanic）：传染/连锁/爆炸/扩散/转化/无敌/免疫/眩晕/替身/首领/精英/递增/联动类——
  如 传染诅咒、毒爆、超载线圈、暴击连击、深冻（冰M4）、永冻（冰M8）、首领（召唤M6）、
  替身（召唤M8）、影步、弹反、血池、圣印、治疗光环 等；
  弱机制/机制初现（冰M1 碎冰、召唤M3 亡语、麻痹、暴击吸血、圣盾护佑 等）→ 蓝

旧 legendary → 红：全量 57 件（顶级语义不缩水）。

### 1.2 法杖（wands.json，55 把）

- 旧 common → 白/绿：价格/强度前 6 强（熔岩/军团/战刃/虚弱/腐蚀/毒刃）→ 绿，其余 7 把 → 白
- 旧 rare → 蓝/金：金 = element_bonus 任一 ≥0.4 或 cd_mult ≤0.85（10 把：毒雾/霜冻/连锁/潮汐/圣光/衰败/亡语/契约/冰环/环绕）；其余 11 把 → 蓝
- 旧 legendary → 红：全量 21 把（含连发/齐射 13 把，硬规则保持）
- 价格带：白 120-250 / 绿 260-360 / 蓝 370-550 / 金 560-690 / 红 700-1200（严格不重叠）
- 价格迁移：带内保留；带外按旧价相对位置映射（6 把绿、11 把蓝中的 2 把、10 把金全部调价，见对照表）

## 8. 风险与说明

- 存档兼容：rarity 不进存档（run.items 只存 id），spell_part id 不变 → 老存档零迁移
- 金/红与既有 GOLD/RED 色系错开（#ffc84d vs #f5b83d、#ff5c5c vs #e05252），面板不混淆
- 红池 21 把占 38%：lucky=0 出红 7.8%，与方案文档预估一致；若仍觉多可后续调权重至 4-5
- 白/绿、蓝/金为 47/65、57/67（≈ 而非严格对半）：白=基础小加成，绿=mechanic 初现或 base≥0.10 明显数值；金=质变机制/大数值清单，蓝=机制初现
