# 元素音效接线报告（combat 3 处命中点）

> 日期：2026-08-13 ｜ 范围：元素命中音效接线（projectile / melee_attack / summon 三处命中点把元素传入 hit_kind_for）｜ 方式：Godot 4.7.1 headless 静态实现 + 自动化测试验证（TEMP/TMP/APPDATA → .tmp）

## 1. 背景与签名

音效换池已在 scripts/core/sfx_bus.gd 的 HIT_SFX 增加 5 个元素 kind（elem_fire / elem_ice / elem_lightning / elem_poison / elem_water），并提供分级助手：

```gdscript
static func hit_kind_for(target: Node, crit: bool, element: String = "") -> String
```

返回优先级：crit > boss > elite > elem_<element>（元素池存在时）> hit（回退）。旧调用（不传 element）默认 element=""，完全兼容。

## 2. 三处接线点与 element 来源

| 命中点 | 位置 | 接线 | element 来源 |
| --- | --- | --- | --- |
| 弹幕命中 | scripts/combat/projectile.gd:459 | SfxBus.play_hit(SfxBus.hit_kind_for(enemy, crit, _element)) | 弹幕自身字段 _element（默认 "fire"，由 setup() 从 spell_caster 注入的 core.element 写入，取值 fire/ice/lightning/poison/water/nature 等） |
| 近战命中 | scripts/combat/melee_attack.gd:123 | SfxBus.play_hit(SfxBus.hit_kind_for(enemy, crit, "blade")) | 固定物理元素 "blade"（与 take_damage(dmg, "blade", crit) / fx_hit(pos, "blade") 一致）；HIT_SFX 无 elem_blade，自动回退 hit |
| 召唤物命中 | scripts/combat/summon.gd:455 | SfxBus.play_hit(SfxBus.hit_kind_for(enemy, is_crit, _element)) | 召唤物字段 _element（默认 "summon"，由 spell_caster 施放时传入核心 element，如 summon_bat → "summon"）；无对应 elem_* 池时回退 hit |

说明：

- 三处均沿用原有的 play_hit(hit_kind_for(...)) 链路，只补第 3 参，不改变 crit/boss/elite 档位优先级（hit_kind_for 内部先判档位再判元素）。
- 元素只替换「普通命中」档位的音色：暴击/精英/Boss 命中仍走 crit / elite / boss 池，打击层次不变。
- 弹幕 _element 与伤害结算 take_damage(dmg, _element, crit)、状态施加共用同一字段，音效与伤害元素始终一致。
