### 1.3 技能模式 → 形态类型映射（视觉区分度核心）

> 调研结论：同类游戏怪物技能的辨识度**不靠伤害数值，靠形态几何**——弹幕（点/线/扇/环/追踪）、地面（圈/池/轨迹）、位移（冲锋/闪现/地刺）、状态（隐身/护盾/狂暴）四层形态互不混淆；单怪技能 ≤2 个，复杂度来自组合。本项目 31 怪按此原则每人 2 技能、且两人技能形态必不同。

### 1.4 本项目落地原则

1. **技能1 = 保留现状**：31 怪现有 behavior 字段原样转正为技能1（不改逻辑、不改数值、不动弹幕视觉）；
2. **技能2 = 新设计**：与技能1 形态不同的新技能，优先复用现有 behavior 逻辑 / Boss 技能类型（18 类可复用，见 §5）；
3. **纯弹幕怪形态差异化**：imp/wizard/goblin_archer/cultist/mummy/bone_arbalest 等"只会射"的怪，技能2 换成闪现/环形/直线狙击/弹幕墙等**非重复形态**；
4. **近战怪非弹幕机制**：slime/bat/goblin/rat/wolf/boar/scarab 等近战怪，技能2 补冲锋/分裂/隐身/自爆/召唤/地面毒圈/流血等**非弹幕独特机制**；
5. **预告铁律沿用**：circle=落点红圈、line=射线红线、dot=发射点；自爆/狙击/激光前摇 ≥0.8s；预告几何 = 伤害几何。

### 2.3 前两份方案与现状的差距（本次要补的）

- 《怪物技能设计方案.md》/《怪物扩展30种方案.md》的 `skills` 数组**尚未写入 enemies.json**（普通怪只有 `behavior` + 参数，无 skills 字段）；

### 4.2 每怪双技能形态差异化校验（31/31 通过）

逐怪核对：技能1 与技能2 形态**无一相同**（程序化校验 31 行 × 2 列，无同行同形态）。示例：imp 扇形弹→闪现、wizard 直线→环形、cultist 扇形→环形、bomber 自爆→冲锋+火带、bone_arbalest 直线→弹幕墙、treant 落点→地刺、ghost 隐身→追踪。

## 六、改动清单（待主 agent 确认后实施）

### 6.1 data/enemies.json（只增不改既有字段）

1. 31 怪每怪新增 `skills` 数组（结构同 Boss，§3 表内容）：`{id, name, type, cooldown, windup, telegraph, ...类型专属参数}`；技能1 = 现 behavior 转正（如 `slime_split` type=split），技能2 = 本表新设计；

3. 新增可选字段：`min_level`（解锁门控）、技能 `elite_mult`（cd×0.8 / 伤害×1.3）；

5. 精英技能池可选扩充：elite_ring / elite_roots / elite_fan（《怪物技能设计方案.md》§4 已定义）。

### 6.2 scripts/enemies/enemy.gd（只增不改既有逻辑）

1. 新增普通怪技能调度器（仿 `boss.gd _pick_skill`）：`skills` CD 到且距离/血线条件满足时施放 1 个；与 `behavior` 被动分派并存；
2. 新技能 cast 函数（P1 组复用 Boss 实现思路改写为小怪版）：`_cast_ring_barrage` / `_cast_homing` / `_cast_blink` / `_cast_beam` / `_cast_summon` / `_cast_self_destruct` / `_cast_spike_trail` / `_cast_wall` / `_cast_zone_status` / `_cast_charge_trail`；
3. 小幅改造：`curse` 行为补 homing 参数（healer/mummy）；`rage` 参数化到 `_ai_melee`（goblin）；`stomp` 抽成可复用（boar 接入）。

### 6.3 scripts/enemies/enemy_bullet.gd（只增参数）

1. `bounce` 参数：撞墙反弹 1 次（scarab bounce_dart，参考 Boss `wall` 的边界处理）；
2. `status` 参数：命中玩家施加 slow/poison（mummy bandage_toss、mushroom spore_zone 相关弹体），复用现有 `apply_slow` 等通道；
3. 现有 homing/视觉逻辑不动。

### 6.4 弹幕视觉（如无缺口则不动）

8 类 `eb_*` 弹体已覆盖本表全部弹幕形态（见 §3 弹幕形态列）；spike_trail/wall/zone 走地面红圈预告（复用 Boss telegraph 系统），**无需新贴图**。可选补充：mummy 缠布弹可加 `eb_bandage`（P2 阶段评估，非必需）。
