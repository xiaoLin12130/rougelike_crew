# 法杖稀有度重分类（2026-08-12）

> 任务：稀有度从「按数值拍脑袋」改为「按机制强度/输出增幅/流派绑定」三要素分档。
> 连发类（shape=rapid 或任意 shape 带 shots>=3）强制升格 legendary。

## 1. 调研：肉鸭游戏稀有度的设计逻辑

| 游戏 | 稀有度判定依据 | 借鉴点 |
|---|---|---|
| 以撒的结合 | 道具强度按「改变 build 的程度」分级：攻击力+、射速+这类数值小改多为普通，而「变形/全家桶/多机制联动」为高稀有度 | 稀有度 = build 改变程度，不是面板数值大小 |
| 吸血鬼僕存者 | 武器进化（Super 武器）靠机制质变（穿透/分裂/环绕/召唤），数值只做配合 | 机制（轨道、连锁、穿透、弹射）> 数值（damage_mult） |
| 土豆兄弟（Brotato） | 装备稀有度按「输出倍率 + 机制」：绿色=基础数值，蓝色=双属性，紫色/红色=高倍率或多机制组合 | 组合键数越多稀有度越高；倍率档位分界明确 |
| 雨中冒险2（RoR2） | 白=小数值，绿=机制初现（链式/爆炸），红=强机制或大倍率 | 机制初现=绿，机制成熟/组合=红 |

**结论**：稀有度应当按「输出增幅 × 机制强度 × 流派绑定深度」三要素综合，而非只看 damage_mult。
本项目 55 把法杖全部属于「强化已有法术 build」的道具，因此：
- common = 平庸数值 / 小加成（单键小数值，element_bonus <= 0.25）
- rare  = 明显强化 或 机制初现（双键组合 / element_bonus 0.3~0.4 / damage_mult >= 1.1）
- legendary = 强机制 / 大倍率 / 多机制组合（三键+ / element_bonus >= 0.45 / 连发类）

## 2. 硬规则（用户要求 + 测试断言）

1. **连发类必须 legendary**：shape == "rapid" 的所有法杖；或任意 shape 下 shape_mods.shots >= 3
   （三连发/四连发/五连发/齐射均属输出倍增机制，直接改变 DPS 量级）。
2. **每流派至少 1 把 legendary**（11 流派全覆盖）。
3. **稀有度与 price 正相关**：common 120-260 < rare 300-600 < legendary 700-1200，区间不重叠。
