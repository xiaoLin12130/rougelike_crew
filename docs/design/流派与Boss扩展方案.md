# 流派技能扩展 + Boss 智能机制方案（v0.2 修订）

> 阶段 0 产物。依据：VerArc 48 图标素材（火/冰/雷/水/藤/光/传送/增益/减益）+ Willibab 武器图标 + 用户需求。
> 目标：构筑深度从"数值"升级为"形态+机制"；Boss 从"大数值沙包"升级为"有机制可学"。

## 0. 构筑倾向加权机制（v0.2 确认版）

- **无流派 tag**：玩家自由组合，不做任何流派限制（内部按元素/类别隐式计算）
- **公式**：元素权重 = 基础权重 × (1 + 0.02 × 持有该元素件数 × 关卡系数)
  - 关卡系数 = 1 + 0.25 × (关卡-1)（L1=1.0 / L3=1.5 / L5=2.0）
  - 总权重提升上限 +60%；非主流元素合计保底 25% 出现概率
- **验证**：模拟测试 1000 局统计流派聚焦度曲线（+2% 基准/关卡联动），确认后定死数值

## 4. Boss 技能机制（6 Boss，数据表 + 状态机）——全部 Boss 都有独特机制

### 通用智能（所有 Boss）
- **距离感知**：近战 Boss 主动逼近、远程 Boss 保持 200-300px 风筝
- **技能节奏**：技能冷却管理（不连续重复、按模式循环：移动→施法→预警→施法）
- **预警系统**：所有可躲避技能先出预警（地面红圈/红线/闪烁 0.5-0.8s）
- **转阶段演出**：血线触发时 0.8s 无敌 + 全屏闪光 + 台词提示 + 清屏冲击波
- **玩家状态感知**：玩家低血时触发"追击"模式（移速+30%）

### Boss AI 状态机（boss.gd 重构）
```
IDLE → APPROACH（逼近/风筝）→ WINDUP（预警）→ CAST（施法）→ RECOVER（硬直 0.5s）
血线触发 → TRANSITION（无敌+演出）→ 进入新技能池
```

## 4.1 防御流（v0.2 替代圣光流）

- **防御值**：磐石护甲（减伤 +8%/层，上限 50%）
- **反甲**：荆棘甲改造——受击反弹所受伤害 40% + 15%/层（反弹给攻击者）
- **反甲吸血**：血棘甲（新道具）——反弹伤害的 **12%** 回血（防御流专属，非攻击吸血）
- **吸血数值规范（全局防无敌）**：
  - 吸血牙：1% + 0.25%/层（上限 **3%**）
  - 反甲吸血：反弹伤害的 **8%** 回血
  - 全来源吸血合并**总上限 5%**（任何叠加不超过）
  - 治疗保持稀缺：击杀掉落 2%、Boss 战后 30%、商店恢复药限购 1
