# 藤蔓护盾音效修复报告

> 日期：2026-08-12 ｜ 范围：藤蔓（thorn_vine）弹体视觉 / 玩家护盾视觉 / 音效重选（参考土豆兄弟 Brotato）｜ 方式：headless 静态实现 + 自动化测试验证

## 1. 藤蔓技能弹体视觉修复（问题 1）

### 1.1 问题

此前 P0-1 修复给 `STATUS_TEXTURES` 补了 `nature → thorn_vine_spell.png`（16x16 静态图标），玩家发射藤蔓技能时看到的是**技能图标直接飞出去**，观感差。

### 1.2 方案（"投出种子，命中缠绕"）

- **飞行阶段**：不再飞任何静态贴图。`projectile.gd` 新增内嵌类 `VineSeedVisual`（纯程序化 `_draw`，无新素材）：深绿种子主体 + 高光点 + 脉动光晕 + 身后 6 段曲线藤须拖尾（sin 摆动，体现"种子带着藤蔓飞"）+ 尖端两片嫩芽；种子随飞行方向旋转（`_dir.angle()`），homing/反弹转向时自动跟随。
- **命中阶段**：直击命中点 / AOE 爆炸点调用 `FxManagerScript.spawn_ground_fx("vine", ...)`（复用既有 GroundVine 地面工厂）：半径 40px（AOE 时取爆炸半径 55%，下限 30px）、存活 1.5s。
- **生长动画**：`fx_manager.gd` 的 `GroundVine._draw` 增加生长进度 `grow`（前 30% 寿命卷须从中心 20% 伸展到全长，透明度同步渐显），命中点呈现"藤蔓长出来/缠绕"的动态，而非瞬间冒出一坨。
- **连带影响**：split 分裂小弹继承 element=nature，自动获得同款种子视觉；水弹保持水滴图标（用户未反馈，不动）。

### 1.3 修改文件

- `scripts/combat/projectile.gd`：`_apply_visual`（nature 分支隐藏 Sprite2D + 建 VineSeed）、`_hit_enemy` / `_explode_at`（生成 GroundVine）、`_reset_for_pool`（清理种子节点）、新增 `VineSeedVisual` 内嵌类与常量。
- `scripts/fx/fx_manager.gd`：`GroundVine` 生长动画。
- `scripts/tests/test_visual_mapping.gd`：nature 断言从"贴图路径==图标"改为"Sprite2D 隐藏 + VineSeed 存在"。

## 2. 玩家护盾视觉（问题 2）

### 2.1 问题

之前只做了 HUD 血条上的灰色护盾叠层，玩家角色身上没有任何护盾表现。

### 2.2 方案

- **常驻光环**：`player.gd` 挂载新增 `scripts/player/shield_aura.gd`（`ShieldAura` 节点，z=-1 脚底偏移跟随移动）：淡蓝半透明圆环 + 脚下柔光（呼吸脉动）+ 内亮环 + 4 段顺时针旋转刻度 + 顶部高光点。每帧只读 `defense_synergy._shield`（与 hud.gd 同款按脚本路径定位，未挂载返回 0）→ **护盾 > 0 显示、归零隐藏**。
- **护盾受击反馈**（`fx_manager.gd`）：
  - `EventBus.player_hit` 时若护盾在场：生成 `ShieldRipple` 浅蓝扩散环 + 白闪，播放 `shield_hit` 玻璃叮音（**替代** hurt 闷响——护盾挡伤不应是肉身闷响）；
  - 护盾破碎（>0 → 0）：双环 + 全白闪 + 6 段碎点外圈，播放 `shield_break`（复用既有 `sfx_shield_down.ogg` 专用素材）；
  - 护盾升起（0 → >0）：小涟漪 + `sfx_shield_up.ogg`（既有素材此前从未被使用）。
- 破碎/升起判定放在 fx_manager `_process` 帧末（player_hit 同步回调时 defense_synergy 尚未结算护盾，必须帧末比对前后值）。

### 2.3 修改文件

- `scripts/player/player.gd`（挂载）、新增 `scripts/player/shield_aura.gd`、`scripts/fx/fx_manager.gd`（`spawn_shield_hit_fx` 静态工厂 + `ShieldRipple` 内嵌类 + `_track_shield_state` + `_on_player_hit` 护盾分支）。

## 3. 音效重选（问题 3，参考土豆兄弟）

### 3.1 音效设计规范（查证：Godot 音频文档 + Brotato 领域知识）

Brotato 作为像素风肉鸽的音效特征：

1. **短促**：战斗音效普遍 0.1~0.3s，长音只在升级/大事件出现；高攻速下互相不糊。
2. **清脆高音调**：命中多为 tick/啪嗒类高频瞬态，低频闷响留给受击与 Boss。
3. **分级辨识**：命中/暴击/击杀/升级各有独立音色，玩家凭耳朵即可判断事件（无需看屏幕）。
4. **UI 轻快**：购买/升级咔哒声短而亮，不粘手。

本作映射规范：

| 用途 | 音色要求 | 目标时长 | 音量 |
|---|---|---|---|
| 命中 | 干爽短 tick，高音调 | 0.1~0.2s | -8db，pitch 1.15~1.2 |
| 暴击 | 明亮重碎（玻璃） | 0.2~0.4s | -5db |
| 精英 | 金属中音 | 0.1~0.3s | -6db，pitch 0.95 |
| Boss | 厚板低沉 | 0.35~0.5s | -4db，pitch 0.82 |
| 击杀 | 清脆小碎裂 | 0.2s | -7db |
| 受击 | 厚重闷响 | 0.5s+ | -7db，pitch 0.9 |
| 升级 | 明亮上扬 chirp | 0.2~0.3s | -8db |
| 购买 | 清脆咔哒 | 0.05~0.15s | -8db，pitch 1.05 |
| 护盾受击 | 玻璃/能量叮 | 0.1~0.3s | -6db，pitch 1.1 |
| 护盾破碎 | 低沉碎裂 | 0.4s | -5db |

### 3.4 变更

- `assets/audio/`：新增 28 个 ogg（Kenney CC0，含许可以原有 license 文本覆盖），删除 20 个无引用旧 ogg（含 .import）。
- `scripts/core/sfx_bus.gd`：`HIT_SFX` 全量重映射 + 新增 `shield_hit` / `shield_break` 两个 kind；`hit_kind_for` 防御性判断（`== true` 替代 `bool()`，避免缺字段目标报错）。
- **无需用户下载**：所有选型均从已下载的 Kenney Impact/Interface Sounds 包内解决；若后续想进一步贴近 Brotato，可再评估 Kenney RPG Audio（氛围）或 itch.io 免费包（见下）。

### 3.5 可选（非必需）后续素材清单

当前不阻塞。如用户希望更"肉"的打击感，可考虑：Kenney "Impact Sounds" 的完整包已有；备选免费源：OpenGameArt 搜 "retro hit sfx"、itch.io 的 "8-bit SFX pack"（均需核对 CC0 授权）。
