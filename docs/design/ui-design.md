# UI 设计规范 v2（像素肉鸽）

> 2026-08-09 v2：从"参考原则"升级为**可执行设计系统**（token + 组件 + 固定布局图 + 验收管线）。
> 依据：ui-rag 知识库（H:\ai-playbook\ui-rag）+ 参考游戏布局（RoR2/VS/魔法工艺）+ 像素级视觉测试实测。

## 1. 设计 Token（所有 UI 代码必须从这里取值，禁止魔法数）

### 1.1 色板（已实现在 scripts/ui/ui_theme.gd）

| Token | 值 | 用途 |
|---|---|---|
| bg | #14111f | 主背景/暗面 |
| panel | #201a30 | 面板底色 |
| panel_light | #2a2340 | 面板高亮/hover |
| border | #8b5cf6 | 主描边（紫） |
| border_dim | #4c3a7a | 次级描边 |
| gold | #f5b83d | 强调/数值/获得提示 |
| red | #e05252 | 危险/玩家血 |
| green | #6fce6f | 回复 |
| 稀有度 | common #b8b8c8 / rare #4a9eff / legendary #ffa726 | 物品/卡片边框与文字 |
| 元素色 | fire/ice/lightning/poison/blade | 投射物与特效 |

### 1.2 字号阶梯（640x360 视口基准）

| 档 | 字号 | 用途 |
|---|---|---|
| caption | 9-10 | 格子内名称、次要信息 |
| body | 11-12 | 说明、标签、金币 |
| title | 14-16 | 分区标题、按钮 |
| heading | 20-26 | 弹窗标题 |
| display | 30-44 | 主菜单标题 |

### 1.3 间距与圆角

- 间距：4px 栅格（4/8/12/16），容器 separation 4-8，面板内边距 8-12
- 圆角：组件 3-4px，面板 6px
- 描边：常驻 1-2px，交互态 2-3px
- 触屏目标：逻辑尺寸 ≥22px（1280x720 窗口 = 44 物理 px），按钮 32-44 高

## 2. 组件规范（统一走 UiTheme 工厂）

| 组件 | 规格 |
|---|---|
| 按钮 UiTheme.button | 深底+紫描边+金字，hover 提亮，pressed 内缩，focus 无框 |
| 物品格（HUD 底部） | 46x32：图标16(EXPAND_IGNORE_SIZE)+名称8-9px+×N 9-10px金；稀有度边框；点击弹详情；新获得脉冲 |
| 血条 | 玩家：蓝/黄填充条纹理(9宫格边距2)+深底描边；Boss：红填充纹理，宽220x12 |
| 面板（构筑/弹窗） | 深底+主描边 3px+圆角 6，半透明 0.75-0.85 不遮操作 |
| 升级卡片 | 165x145：图标34居中+名称13+描述10（描述区固定高34防高度不齐），稀有度边框，悬停提亮 |
| 详情弹窗 | 居中 300x200，全屏暗化遮罩(点击关闭)，图标+标题+描述+标签 |

## 3. 固定布局图（640x360 视口，元素互斥关系即测试断言）

```
┌─资源区 x8..160 ───────────┐ ┌Boss条 x170..550 y4..20┐ ┌波次 x332..632 y28..48┐
│ HP行 y6..20   Lv y23..38  │ └────────────────────────┘ └──────────────────────┘
│ XP条 y41..47  金币 y50..64 │
│ 击杀 y67..81              │
├───────────────────────────┤
│                    中下: 获得提示 x170..470 y234..256│
│                右下: DPS x500..630 y304..320          │
├─左下: 构筑条 x27..513 y310..350（可折叠→仅tab按钮）──┤
└───────────────────────────────────────────────────────┘
```

互斥断言（hud_layout_test.gd 强制）：
1. Boss 条 ∩ 资源区 = ∅（x 分界 160/170）
2. Boss 条 ∩ 波次横幅 = ∅（y 分界 20/28）
3. 构筑条 ∩ DPS = ∅（DPS 在构筑条上方）
4. 构筑面板打开时构筑条自动收起
5. 全部元素 rect ∈ [0,640]x[0,360]

## 4. 像素级视觉验收（web_hud_visual_test.py）

CDP 截图 + 颜色断言（1280x720 headless Chrome）：
- 左上 HP 条蓝色填充 >5%
- 底部构筑条深色面板 >15%（折叠后 <60% 原值）
- 顶部中央无红色遮挡（Boss 条未显示时）
- 详情弹窗面板色占比 >20%
- 每关画面截图存档 .tools/v2_*.png 供人工复核

## 5. 开发流程（防错位铁律）

1. 改 UI 前：`python H:\ai-playbook\ui-rag\search_ui.py "..." -k 3` 检索知识库
2. 改完：`godot --headless -s res://scripts/tests/hud_layout_test.gd`（布局断言）
3. 再跑：`python tools/scripts/web_hud_visual_test.py`（像素断言，需提权）
4. 全绿后导出交付；视觉测试失败 → 看 .tools/v2_*.png 区域分析修复
