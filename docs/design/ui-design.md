# UI 设计规范 v1（像素肉鸽）

> 依据：同类游戏 UI 实证（Risk of Rain 2 / Vampire Survivors / 魔法工艺 / Hades / 以撒）+ 通用 HUD 设计原则
> （已检索：Bing/DDG 多轮、gameuidatabase、80.lv；站点反爬导致部分不可达，原则来自公开行业共识与游戏实证）

## 1. 参考游戏的关键做法

| 游戏 | 可借鉴做法 |
|---|---|
| Risk of Rain 2 | **道具栏常驻屏幕底部**（图标+层数横排，即"构筑直接可见"）；左下血条；右下主动装备位 |
| 魔法工艺 | **法杖法术网格常驻底部**（核心+外壳图标，冷却转圈）；右侧遗物图标列 |
| Vampire Survivors | 升级**三选一全屏大卡片**（图标+名称+描述，稀有度配色）；HUD 极简 |
| Hades | 顶部资源条；技能槽位带冷却；面板层次分明（半透明+描边） |
| 以撒 | 血量图标化（心形）；主动/被动图标常驻 |

## 2. 视觉语言（像素风）

- **配色**：深底 `#14111f`；面板 `#201a30`/`#2a2340`；描边紫 `#8b5cf6`；高亮金 `#f5b83d`；危险红 `#e05252`；生命绿 `#6fce6f`
- **稀有度**：普通灰 `#b8b8c8`、稀有蓝 `#4a9eff`、传说橙 `#ffa726`
- **元素色**：火 `#ff7b3d`、冰 `#7fd4ff`、雷 `#ffe95c`、毒 `#7ed957`、刃 `#c8d0e8`
- **组件**：面板 = 深色底 + 1-2px 亮描边 + 4px 圆角（StyleBoxFlat）；按钮 = 深底 + 紫描边 + 金色文字，hover 提亮、按下内缩；所有文字带像素风描边
- **字体**：中文 NotoSansSC（正文 10-12px，标题 20-32px）；数字/英文 kenvector_future
- **信息层级**：HUD 左上=生命/资源，左下=构筑常驻条，右上=临时提示（波次），右下=性能信息

## 3. HUD 布局（640x360 基准）

```
┌─左上：HP条+数值─────────┐ ┌右上：波次横幅┐
│ Lv 经验条               │              │
│ 金币  击杀·轮次          │              │
├──────────────────────────┤              │
│                          │        右下：DPS│
├─左下：构筑条──────────────┴──────────────┤
│ [法杖格×5][道具图标+层数×10] [构筑][暂停] │
└──────────────────────────────────────────┘
```

- 构筑条**常驻**：法杖 5 格显示核心图标+外壳小标，道具图标+层数角标（>10 个显示前 10 + "+N"）
- 点击「构筑」展开完整面板（排序交换、饰品、技能记忆）

## 4. 关键界面

- **主菜单**：暗紫渐变背景 + 浮动星点粒子 + 大标题（金色描边）+ 版本号 + 操作说明 + 三个像素按钮
- **升级三选一**：暂停时全屏暗化，三张卡片（图标+名称+描述+稀有度边框），hover 高亮
- **抉择/结算/暂停**：统一面板样式，大标题 + 统计 + 按钮
