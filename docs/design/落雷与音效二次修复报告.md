## 1. 连杀落雷门控（问题 1）

### 1.1 问题

`fx_manager.gd:1661` `_on_enemy_died` 连杀反馈：2 秒内击杀 >= 6 触发慢动作时，无条件
`EventBus.fx_explosion.emit(pos, "lightning")` —— 无雷系构筑也会莫名闪雷。

### 1.2 修复

- 加雷系门控：`_school_holdings_of("lightning") > 0` 才发 lightning；无雷系改发
  `gold` 金色庆祝粒子（金币雨语义，保留"爽感"档位）。
- 附带：`fx_manager.gd:534` 护盾升起音量 -10dB -> -11dB（对齐音效降档，见 §3）。

## 2. items.json 描述码点（问题 2）

### 2.1 字体证据

- 主字体 `assets/fonts/LXGWWenKai_subset.ttf`（2026-08-10 19:18 重新生成，6894 字形）经
  fontTools cmap 检查**已覆盖** ≥ × ÷ → · 等符号；但数字字体 `kenvector_future.ttf`
  （214 字形，仅 ASCII，用于部分数字 UI）不覆盖任何非 ASCII —— 这就是"渲染成 ?"的路径。

  （兼容旧子集与 kenvector 路径，防子集再生成时丢字形）。

## 3. 音效重审（问题 3）

### 3.1 查资料结论

- Godot 官方文档（.tools/godot-docs 本地缓存 `class_audiostreamplayer.rst`）：
  volume_db 默认 0dB、pitch_scale 默认 1.0、bus 默认 Master、max_polyphony 默认 1；
  对已在播放的实例再次 play() 会重启流。项目无自定义总线布局（仅 Master），
  故采用**逐 kind 音量降档**而非新增总线。
- Brotato/像素肉鸽音效特征：短促（战斗音 0.1~0.3s）、音量适中不刺耳、分层
  （UI 低 / 战斗中 / 暴击与 Boss 高但低频）、pitch 变化小、高攻速下不糊。

### 3.2 问题定位（"Herschel 重选"即商店"换一批/购买"，走 `play_hit("buy")`）

| 症状 | 根因 |
|---|---|
| 听不到/刺耳 | buy 池 4 个文件里 select_001/002 仅 **0.043s**（近乎无声 dry tick），50% 概率抽到；pitch 1.05 × 抖动 |
| 太尖 | hit 基音 1.18 × 抖动 ±12%（最高 1.32）；shield_hit 1.12 |
| 太响 | 音量 -4 ~ -8dB（Boss -4dB 偏高），12 个池实例可同时叠加 |
| 太碎 | 同 kind 节流 0.04s（上限 25 次/秒）在高速构筑下成机枪噪声；命中池仅 3 个文件反复 |

### 3.3 调整明细（sfx_bus.gd）

| 参数 | 修改前 | 修改后 |
|---|---|---|
| PITCH_JITTER | ±12%（0.88~1.12） | **±5%**（0.95~1.05） |
| HIT_SFX_MIN_INTERVAL | 0.04s | **0.05s**（约 20 次/秒/kind，100 连发仍播约 20 个而非 1 个） |
| HIT_SFX_FRAME_BUDGET | 3 | 3（保持） |
| 各 kind 音量 | -4 ~ -8dB | **-12 ~ -8dB**：hit -12 / buy -12 / kill -11 / hurt -11 / upgrade -11 / shield_hit -11 / elite -10 / crit -9 / shield_break -9 / boss -8 |
| 命中基音 | hit 1.18 | **1.02** |
| 其他基音 | boss 0.82 / shield_hit 1.12 / buy 1.05 | boss 0.86 / shield_hit 1.06 / buy 1.0 |
| 映射池 | 每 kind 3 个文件、buy 含 select | **每 kind 4~5 个文件**（降低同音反复），buy 改 pluck+click+toggle |

层级保持：**UI（-12）< 普通战斗（-11/-12）< 精英（-10）< 暴击（-9）< Boss（-8）**。
