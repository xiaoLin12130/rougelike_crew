# 视觉特效强化方案（程序化特效 + 素材缺口清单）

> 日期：2026-08-11 ｜ 调研代理产出 ｜ 铁律：**本轮纯只读，未修改任何游戏代码/场景/数据**；未动 .git。
> 背景：用户反馈"雷云、冰霜等程序化特效不够好看"，要求特效**有区分度、不用简单粒子糊弄、不用贴图冒充特效**。

## 二、同类游戏特效做法（像素肉鸽 / 弹幕参考）【领域知识】

| 游戏 | 弹道拖尾 | 爆炸层次 | 元素区分 | 召唤/武器反馈 |
|---|---|---|---|---|
| 元气骑士 | 弹丸带短拖尾/流光 | 闪光→火球→烟雾→碎屑四层 | 火=三角焰舌、冰=晶簇、电=锯齿、毒=绿泡雾 | 法杖蓄力光点→发射；召唤有落点光圈 |
| 以撒的结合 | 眼泪无拖尾、激光有 | 眼泪爆=水花+碎片 | 火=火球、冰=冰晶、毒=绿云、电=电弧 | 主动道具使用有仪式圈 |
| 挺进地牢 | 弹道细长带尾迹 | 爆炸=闪光+烟+碎屑 | 火=焰、冰=蓝、毒=绿、电=黄 | 翻滚留残影 |
| Brotato 武器 | 快弹道带粒子尾 | 命中爆点=闪光+数字 | 武器贴图即元素签名 | 每武器独立刀光/音色 |

**共性铁律**：① 元素靠**形状签名**区分（不只换色）；② 爆炸 = 闪光 + 主爆 + 扩散环 + 烟雾/碎屑 的层次时序；③ 动态程序化优先于静态贴图；④ 特效节奏与伤害事件同步（预告→爆发→余韵）。

### 3.3 用户点名问题诊断

**雷云（player_aura cloud 层 + lightning KIND_RECIPES shape.cloud）**：
- 现状：player_aura 头顶雷云 = 点状粒子（8px 径向渐变贴图）scale 2.8~4.2 的"灰点堆"；落雷 shape.cloud = 3~5 粒 smoke 0.28~0.35、纯色深灰、无内部闪光 → **云无体积感、无内部电光、无层次**。
- 结论：单层粒子云的"糊弄感"正来自此。

**冰霜（player_aura fog 层 + ice KIND_RECIPES shape.ice）**：
- 现状：冰雾 = 蓝白点粒子漂浮；冰晶 = 5 个随机折线晶簇（`_build_crystal` 单分支无对称）；爆炸 ice shape = 2 簇 size 20 → **晶形单一、无冻结过程、无破碎感**。

## 五、元素程序化方案（具体参数）

### 5.1 雷（重点：雷云 + 落雷）

**雷云三层化**（player_aura `cloud` 层重做 + thunder 爆炸 shape.cloud 升级）：
- 第 1 层 暗云底：3~4 粒 smoke_08/09/10，scale 0.30~0.42，`color Color(0.16,0.17,0.22,0.85)`，life 2.2s，缓慢漂移 vel 4~10，`grow=true` → 云底体积；
- 第 2 层 中云亮边：5~7 粒 smoke_05/06，scale 0.18~0.26，`color Color(0.42,0.45,0.55,0.9)`，加法混合 → 云层受光面；
- 第 3 层 内部电光：每 0.25~0.4s 随机 1 条微型锯齿折线（Line2D width 1.2，`Color(1.0,0.96,0.72)`）在云内闪烁 0.08s + 云底 spark_01 电花 3~5 粒 vel 60~140 → **云在"酝酿"的可读信号**；
- 云底偏移：`offset(0,-72)` 保持；雷云风暴/storm_cloud 物品落点沿用 GroundThunder（已达标）。

**落雷完整时序**（thunder_synergy `_fx_lightning` + lightning KIND_RECIPES，补"预告→爆发→余韵"）：
1. 预告 0.25s：落点出现 1 个暗色雷圈（Line2D 圆，`Color(0.7,0.72,0.8,0.5)`，宽 1.5，静止）+ 云内电光频闪（2 次）；
2. 爆发 0.05s：全屏级闪光（flash light_03 放大到 0.45 + flare_01 可选）；
3. 主柱 0.12s：现有 86px 双层闪电柱（11px glow + 3.4px 白芯）改为 **2 根错相**（第二根延迟 0.04s、偏移 ±10px，模拟多道落雷）；
4. 溅射 0.3s：现有地面电弧 4~6 条保留 + 落点火花 10~16 粒（现有 impact 层）；
5. 余韵 0.5~1.5s：地面电弧微光（GroundThunder 已有）或焦痕 scorch_01 可选。
改动文件：scripts/synergies/thunder_synergy.gd、scripts/fx/fx_manager.gd（shape.cloud 参数）、scripts/fx/player_aura.gd。

### 5.2 冰（重点：晶簇 + 冻结过程 + 破碎）

- **六角对称晶簇**（替换 player_aura `_build_crystal` 与 ice shape.clusters 的随机单分支）：每簇 6 支 60° 对称冰刺（Line2D，每支 2~3 段、长度 10~18px 抖动 ±2px），外层淡蓝 `Color(0.72,0.90,1.0,0.85)` 宽 1.6，内层亮白 `Color(0.9,0.98,1.0,0.9)` 宽 0.8；簇数 3~5，缓慢旋转 0.1rad/s + 呼吸 alpha 0.7~1.0；
- **冻结霜蔓延**（命中/冻结瞬间，新增 shape 类型 `frost_spread`）：从受击点沿 6 个方向（60° 间隔）生成 6 条锯齿霜线（`_jagged` 3 段、长 18~30px），tween 0.18s 内从 0 生长到全长 + 渐隐 0.4s，`Color(0.8,0.93,1.0,0.9)` → 表现"冻结扩散"；
- **破碎碎屑**（冻结结束/冰爆时）：8~12 粒 star_01/spark_04，scale 0.04~0.08，vel 160~320 全向 + grav (0,260)，life 0.35~0.6s，加法混合 → 冰"裂开"；
- 冰爆炸 shape.ice 升级：clusters 2→4、size 20→26，加 frost_spread 层。
改动文件：scripts/fx/fx_manager.gd（KIND_RECIPES["ice"]、新增 shape 分发）、scripts/fx/player_aura.gd。

### 5.3 火（区分度：焰舌 + 灰烬 + 焦痕）

- 主爆三层已有（外焰/内焰/芯），补：

改动文件：scripts/fx/fx_manager.gd（fire 配方 + scorch 层）、scripts/combat/projectile.gd（拖尾）。
