# 数值设计文档 v1.0（DEMO 版）

> 依据：《Game Balance Concepts》（Ian Schreiber，已入库 RAG）+ 四款参考游戏数值实测（见研究报告中数据）
> 原则：全部数值 JSON 表驱动；所有公式必须能被 `tools/tests/test_curves.py` 手算验证。

## 1. 核心公式

### 1.1 伤害

```
最终伤害 = raw × (1 + 攻击加成) × (1 + 元素加成) × 暴击倍率
raw = 技能基础伤害 × (1 + 0.15 × 该技能强化层数)        # VS 式升级
```

- 攻击加成：力量徽章等线性道具叠加（+10%/层）
- 元素加成：与伤害元素匹配的加成（如火伤+冰核心无加成）
- 暴击倍率：暴击时 = 1.5 × (1 + 0.10 × 暴伤层数)，未暴击 = 1.0

### 1.2 暴击（RoR2 四叶草式）

```
暴击率 = clamp(0.03 + 0.02 × 暴击层数, 0, 0.85)         # 线性但封顶
暴击率(幸运) = 1 - (1 - p)^(层数+1)                     # 独立概率式（四叶草）
```

### 1.3 道具叠加四曲线（RoR 式，每个道具声明类型）

| 类型 | 公式 | 参考 | 例子 |
|---|---|---|---|
| linear 线性 | v(n) = base × (1 + k×n) | Syringe +15%/层 | 攻速药水、力量徽章 |
| exp_proc 独立概率 | v(n) = 1 - (1-p)^(n+1) | 四叶草、Tougher Times | 幸运、闪避、冻结 |
| threshold 阈值跳变 | v(n) = base + step×(n // T) | Hardlight 类 | 弹射镜每3层+1弹射 |
| multiplicative 指数 | v(n) = base^n（限量 3-5 层；base<1 时 cap 为下限） | 高稀有道具 | 法杖充能（每层×0.9 CD，下限 50%） |

### 1.4 敌人成长（雨中冒险式，按"轮次 loop"与"关卡 level"双轴）

```
关卡系数   L(level)   = 1.18^(level-1)          # 5 关内
轮次系数   HP  = 1.30^(loop-1)
           DMG = 1.18^(loop-1)
           NUM = 1.25^(loop-1)
敌人HP  = base_hp  × L(level) × 1.30^(loop-1)
敌人攻  = base_atk  × (1 + 0.12×(level-1)) × 1.18^(loop-1)
敌人数量 = base_num × 1.22^(level-1) × 1.25^(loop-1)
经验值  = base_xp  × (1 + 0.10×level) × 1.35^(loop-1)
```

玩家成长必须跑赢 HP 曲线（每关 DPS 预算 ×1.35~1.5），跑赢 = 爽。

### 1.5 玩家成长

```
基础属性：HP 100，移速 220 px/s，基础DPS ≈ 25（第1关小怪 2-3 击）
升级经验：xp_to_next(L) = 60 + 35 × L
升级奖励：三选一（武器升级/新道具/法术碎片/恢复）
```

### 1.6 击杀时间预算（TTK）

| 单位 | 击杀时间 | 说明 |
|---|---|---|
| 小怪 | 0.5-2s（1-3 击） | 保证割草节奏 |
| 精英（词缀） | 4-8s | HP×4、攻击×1.5、体型×1.4 |
| 关卡 Boss | 30-60s | 有阶段转换 |
| 最终 Boss（古神） | 60-90s | 三阶段 |

### 1.7 掉落与保底

```
击杀掉落（概率表，和为 1）：
  金币 0.80 / 道具 0.08 / 法术碎片 0.07 / 饰品 0.05
保底：连续 8 次击杀无道具 → 下一次必掉道具（pity 计数器）
Boss 必掉：1 传说道具 + 2 稀有道具 + 金币 ×5
```

### 1.8 爽感阈值（视觉档位开关）

| 档位 | 条件 | 视觉反馈 |
|---|---|---|
| 成型 | 本关清场时间 < 45s | 粒子密度 ×1.5，伤害数字变大 |
| 碾压 | DPS ≥ 敌人总血量 × 1.2 /s | 全屏粒子 + 数字放大镜 + 击杀溅射 |
| 质变 | 触发进化合成 | 全屏闪光 + 0.3s 慢动作（time_scale 缓动） |

## 2. 六流派数值骨架

| 流派 | 关键道具/法术 | 数值目标（成型后） |
|---|---|---|
| 元素弹幕 | 火球+齐射+弹射，攻速×3，暴击 30% | 每秒弹幕数 ≥ 20，清屏 < 30s |
| 召唤 | 蝙蝠召唤+召唤书×4，光环饰品 | 召唤物 ≥ 6，总 DPS 玩家 ×2 |
| 近战狂暴 | 旋风刃+攻速×3+吸血 8% | 移速 300+，吸血回满 < 3s |
| 冰冻控制 | 冰锥+冻结饰品 25%，碎冰联动 | 冻结覆盖率 ≥ 60%，碎冰连锁 |
| 暴击暴伤 | 暴击 60%+暴伤 ×2.5，四叶草 | 暴击期望 ≥ 90%，单发 ≥ 3000 |
| 诅咒传染 | 毒雾+毒液瓶叠层+扩散 | 一跳毒伤链条全屏，DOT 占比 > 60% |

## 3. 数据表文件（data/）

| 文件 | 内容 |
|---|---|
| balance.json | 核心公式常量（基础属性/TTK/成长系数/爽感阈值） |
| items.json | 道具定义：id/名称/稀有度/曲线类型/参数/图标 |
| spells.json | 法术核心+外壳定义：基础伤害/CD/射程/修饰参数 |
| enemies.json | 敌人定义：基础HP/攻/速/尺寸/掉落/词缀模板 |
| levels.json | 5 关配置：敌人组成/数量/时间线/Boss |
| drops.json | 掉落概率表与保底参数 |

> Schema 契约见 `docs/design/data-schema.md`；所有表由 `tools/tests/test_curves.py` 做一致性校验（曲线单调、概率和为 1、无负值）。
