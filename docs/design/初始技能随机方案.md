# 初始技能随机方案（2026-08-12）

> 需求：开局固定火球/旋风刃改为随机 2 个「核心×外壳」技能，两个技能流派（核心 element）必须不同。

## 1. 原状（game_state.gd new_run）

以前：固定 fireball + whirl_blade 两个核心，外壳随机。
问题：每局开局都是火+刀，流派发展方向受限；外壳随机无筛选，可能出现无效组合。

## 2. 新实现（同文件）

- `_roll_starter_core_pool()`：抽出核心池，仅保留至少有一个有效外壳组合的核心
  （frenzy/mana_echo 对所有外壳零消费/冲突，全部过滤，保证开局技能必带外壳）。
- `_roll_valid_shell(core)`：按 _invalid_combo 审计的有效外壳池随机抽 1 个。
- `_roll_starter_grid()`：先随机核心 1（流派 A），再从流派 != A 的池中随机核心 2（流派 B），
  每个核心各配一个有效随机外壳。两个技能流派必须不同。

## 3. 细节

- 流派判定：核心的 element 字段（fire/ice/lightning/poison/summon/blade/water/
  nature/light/void/buff 等），与 school_holdings 的统计键保持一致。
- 外壳可能为空（“原生”）的情况不会出现：核心池本身已过滤出“至少有一个有效外壳”，
  故每个开局技能都带外壳。
- 抽取均可重复（随机替换不退出），不影响结果合规性。

## 4. 测试：scripts/tests/test_starter_spells.gd（新增）

30 次开局，断言：
1. grid 数量 == 2；
2. 每个技能 core/shell 非空且 id 存在于 data/spells.json；
3. 两个技能核心 element 不同；
4. 组合经 _invalid_combo 验证有效。
运行：`godot --headless --path . -s res://scripts/tests/test_starter_spells.gd` → STARTER SPELLS TEST OK
