## 1. Brotato UI 调研结论

### 1.1 游戏内 HUD（M + 截图佐证）

- **左上角资源区**：HP 条（数值文本 + 横条；有护盾时护盾以浅色叠层压在 HP 条上），下方为**材料计数**（材料图标 + 数字）。材料（Materials）是 Brotato 唯一货币，兼作经验来源——击杀掉落的材料块自动飞向玩家。
- **顶部中央**：波次信息 + 倒计时（每波 20-90s），带时间进度感（横幅/计时条）。
- **底部中央武器栏**（M，核心特征）：最多 6 个武器槽，槽内为**武器图标 + 堆叠数量（×N）**——Brotato 的构筑表达就是"同一武器叠 N 个"，道具（被动）**不**常驻显示在战斗 HUD，只在商店/统计面板查看。
- **Boss/精英**（M）：Boss 出现时顶部出现大血条（名字 + 红条），位置与常驻 HUD 互斥错开。
- **伤害数字**：飘字，暴击更大并变色（本项目已有 damage_number）。
- **TAB 统计面板**（H：Endless 截图 + Stats 页）：按 Tab 打开全屏属性表，16 项主属性**两列排列，每行 = 图标 + 名称 + 数值**，负值标红。
- 升级发生在战斗内（弹层 4 选 1）与商店内均可（H：Upgrades 页）。

### 1.2 商店（H：wiki Shop 页 + 商店截图分析）

- 每波结束**自动进入商店**，标题显示刚结束的波次号。
- 单次提供 **4 个商品**（武器/道具混合；前 5 个商店有特殊限制）。
- 商品呈现为**等宽等高的卡片**，截图布局（2048x1089 分析结果）：
  - 顶部通栏：左 = 大标题（WAVE 编号），右 = 材料数；
  - 中部一行 4 张卡：每卡 = 图标区（上）+ 名称区（中）+ 价格区（下，材料图标+数字）；
  - 卡下方一行 4 个**锁定钮**（挂锁），右侧一个**刷新（Reroll）按钮**；
  - 底部区域：角色/已持有槽位区 + 大按钮（开始下一波）。
- **刷新定价**（H，公式）：首刷 `floor(Wave*0.75) + floor(0.40*Wave)`（最小 1），之后每次 `+floor(0.40*Wave)`；每次进店重置。买齐 4 件送 1 次免费刷新；锁定商品不随刷新更换且**保价**。
- **价格通胀**（H）：商品价 = 基础价 × 稀有度系数，并随波次上涨（锁定可保价）；Coupon 等道具可减价。
- 商店是**武器的唯一来源**，道具还可在关卡中开箱掉落（H）。
- 商店内也会弹出升级选择（H）。

### 1.3 升级表现（H：Upgrades 页）

- 升级提供 **4 张升级卡**（本项目为 3 张，属合理差异），每张 = 单项主属性 + 数值（图标 + 名称 + 数值）。
- 升级分 **4 档（I/II/III/IV）**，同属性高档数值更大（如 Max HP +3/+6/+9/+12）。
- **升级选项可刷新**（与商店共用同一刷新价格体系；一次升级与商店之间价格独立，但同波内多次升级共享）。
- 卡片带稀有度/档次边框。

### 1.4 统计面板（H：Stats 页 + Endless 截图）

- 16 项主属性：Max HP、HP Regeneration、Life Steal、Damage、Melee Damage、Ranged Damage、Elemental Damage、Attack Speed、Crit Chance、Engineering、Range、Armor、Dodge、Speed、Luck、Harvesting（DLC 另有 Curse）。
- 面板结构（Endless.png 分析）：顶部通栏（波次/材料），主体**两列统计行**（图标+名称+数值），底部通栏（重点数值/按钮）。截图还显示属性**可为负**（负面流派）。

### 1.5 元进度 / 图鉴（H：Progress 页）

- 挑战网格：危险等级（Danger 0-5）、击杀数（Survivor）、收集材料数（Gatherer）、杂项成就（死亡/负回血/高闪避…），每项解锁一个角色。形式上与本项目图鉴（收集 → 解锁信息）同构。

### 1.6 视觉风格（H：图标样本实测 + 截图）

- **图标**：32px 级像素、单图标 7-27 色、**重暗色描边**、扁平明暗两段式。实测：Attack Speed = 白/灰闪电；Brain（元素伤害）= 白底+黑描边；Armor = 金色系 22 色。与本项目 shikashi/willibab 图标（约 32px、暗描边、有限调色板）风格同源。
- **面板**：深色（近黑蓝灰）底 + 浅灰蓝 1px 边框 + 卡片分区；商店截图整体低饱和（wiki 图疑似灰度化，布局不受影响）。
- **字体**：像素风数字/标题（本项目 kenvector_future 同类型），中文说明用小字号像素体。
- **稀有度**：五档色（common 灰 / uncommon 绿 / rare 蓝 / epic 紫 / legendary 橙）。
- **按钮**：深底 + 亮边框，悬停提亮，价格/货币用金色。

### 1.7 信息密度高而不乱的原因（H/M，本项目借鉴要点）

1. **固定分区**：左上=生存资源、顶中=时间、底中=构筑、右下/底部=操作，任何弹层不侵占战斗视野中心。
2. **卡片化 + 统一栅格**：商品 4 卡一行等宽等高；统计面板两列等行高；升级卡等宽。
3. **三级层次**：面板 > 卡片 > 图标，边框宽度分级（1/2/3px），同一时间只有一个"主层次"在吸引注意。
4. **颜色语义化**：材料金/棕、HP 红、护盾蓝灰、稀有度五色、负属性红；语义色 < 6 种。
5. **常驻信息极少**：战斗 HUD 只显示"血/材料/时间/武器堆叠"，其余全部折叠进 Tab 面板/商店。
6. **固定间距刻度**：卡片间距、行距、内边距全部统一，靠留白分区而非画线。

## 3. 适配总原则

1. **只动 UI 层**：全部改动落在 scripts/ui/、scenes/ui/、assets/ui/ 与 ui_theme.gd；不碰战斗/数据/存档。
2. **Brotato 取"信息架构与密度管理"，雨中冒险取"构筑面板 + TAB + 图标×数量"**，两者都以"常驻 HUD 极简、细节进面板"收敛。
3. **沿用竖版 360x640 逻辑画布**：PC/手机共用布局骨架，`is_mobile()` 分支只调字号/尺寸/网格列数（沿用现有模式），不新造横版坐标系。
4. **颜色只扩展不推翻**：保留现有紫色主题作为"稀有度/强调"辅助，新增一组 Brotato 调性 token（面板灰蓝、材料金、负值红）。
5. **互斥断言优先**：新增任何顶部元素都必须满足 hud_layout_test 的互斥规则（见 5.2.5），保证 Boss 条不挡经验条、波次横幅不重叠。

### 4.3 间距/圆角/描边

- 圆角：槽位 3px，卡片 4px，面板 6-8px（延续现状）。
- 描边：面板 1-2px（灰蓝），卡片按稀有度 2-3px，交互态 3px。
- 触控目标：手机分支 ≥44x44（现状约束，保留）。
