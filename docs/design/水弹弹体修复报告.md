# 水弹弹体修复报告

> 日期：2026-08-13 ｜ 范围：water_bolt 弹体视觉修复 + 15 核心"图标当弹体"全量排查 ｜ 方式：headless 静态实现 + 自动化测试验证

## 1. 水弹弹体修复说明

### 1.1 问题

用户反馈"水弹技能是直接把图标发射出去的"。根因：

- `scripts/combat/projectile.gd` `STATUS_TEXTURES` 字典中 `"water"` 映射到 `res://assets/icons/verarc/water_spell.png`（16x16 技能图标），弹体直接把技能图标飞出去，观感差。
- 同期为补偿 16x16 > 常规 12x12 贴图差异，`STATUS_TEXTURE_SCALE["water"] = 1.5`（放大补偿）。
- 对比 fire/ice/lightning/poison/blade 均使用 `assets/sprites/gen/proj_*.png`（12x12 程序化弹体贴图）；nature（藤蔓）此前已改程序化种子视觉（`VineSeedVisual`，`_apply_visual` 276-286 行），water 未处理，成为最后一个"图标当弹体"的残留项。

### 1.2 修复方案

**任务 1：新增程序化水弹贴图 `assets/sprites/gen/proj_water.png`**

12x12 RGBA，与现有 `proj_fireball.png` / `proj_poison.png` 同风格（深色 1px 描边 + 主体 + 高光），绘制为"圆形水滴"：

- 圆主体：中心 (5.5, 4.0)、半径 3.7；
- 底部略尖成水滴形：y ∈ [8.0, 10.5] 半宽由 1.9 线性收窄到 0.3（尖端朝下）；
- 配色：描边 `#1a3a6a`（深蓝）、主体 `#3a9df0`（亮蓝）、高光 `#b8e6ff`（浅青，左上 (3,2)(4,2)(3,3)(4,3) 四像素）。

生成方式：Python PIL 程序化绘制（无手绘/外部素材），像素网格已验证。

**任务 2：修正 `projectile.gd` 映射**

- `STATUS_TEXTURES["water"]`：`res://assets/icons/verarc/water_spell.png` → `res://assets/sprites/gen/proj_water.png`；
- `STATUS_TEXTURE_SCALE["water"]`：1.5 → 1.0（12x12 与 fire/ice 同规格，无需放大补偿）；
- `_apply_visual` 第 288 行统一逻辑不变（water 走常规程序化弹体分支）。

`"nature"` 条目保留为兜底（实际由 `VineSeedVisual` 分支接管，不读取），注释同步更新避免误导。

| `projectile.gd` `_apply_visual` whirl 分支 | `willibab/SWORDS_120.png` | 宽刀刀身贴图（33x33 武器素材，非技能图标语义），1.8x 旋转为 2026-08-10 用户反馈修复，**合理** |

## 4. 附带发现（非本次改动范围）

- `STATUS_TEXTURES` 无 void/light/buff/summon 条目：这些元素均为瞬发/召唤/特殊核心，不生成飞行弹体，回退 fire 不可达，无实际影响。
- 潜在边缘路径：flash（light）+ split 外壳时，分裂小弹继承 element=light → `STATUS_TEXTURES` 无 light 会回退火球贴图。可选项：补一张 `proj_light.png`（金色光点）或给小弹指定元素贴图（P2，本次不动）。
