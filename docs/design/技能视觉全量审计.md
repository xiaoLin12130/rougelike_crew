# 技能视觉全量审计（旋风刃同类问题排查）

> 审计日期：2026-08-10 ｜ 方式：纯只读静态审计（未运行 Godot）
> 背景：用户反馈"旋风刃刀刃太小看不出是刀在转"，已修复（SWORDS_120 宽刀 1.8x + 刀尖朝外自转）。本审计排查**其余技能是否存在同类问题**：技能视觉与技能语义/玩家预期不符（形状错、太小不明显、颜色不对、特效缺失）。
> 范围：15 个法术核心 + 10 个外壳的**施法视觉**（弹道贴图 / fx_cast 施法特效 / fx_hit 命中 / fx_explosion 爆炸）。

## 0. 参考基准：旋风刃已修方案（问题模板）

- `scripts/combat/projectile.gd:85-90` `_is_whirl` 分支：`SWORDS_120.png`（33x33 宽刀，主体青蓝）+ scale 1.8（渲染约 59px，> 玩家 32px）+ 刀尖朝外自转（`_orbit_step` 中 `rotation = _orbit_angle + PI/2`）。
- 结论：**尺寸明显（59px vs 玩家 32px）、形状正确（宽刃刀）、朝向语义正确（刀尖朝外转）**。已修 ✅。
- 其余技能以此为模板逐项对照：形状/尺寸/颜色/特效四要素。

## 3. 问题清单（含可落地修复建议）

### P0（视觉与语义严重不符，玩家直接误解）

1. **water_bolt 弹体是火球**
   - 当前视觉：`proj_fireball.png`（橙红圆球，12px）飞行；命中后才是蓝色水花。
   - 原因：`projectile.gd:17` STATUS_TEXTURES 只有 fire/ice/lightning/poison/blade，`:92` 缺省回退 fire。
   - 建议：① `STATUS_TEXTURES["water"] = "res://assets/icons/verarc/water_spell.png"`（16x16 蓝水滴，scale 1.5 ≈24px，参考旋风刃思路）；② 或新绘 12px `assets/sprites/gen/proj_water.png`（蓝水滴，锥尖朝前）。muzzle/hit/explosion 已是水色涟漪，无需改。

2. **thorn_vine 弹体是火球**
   - 当前视觉：火球贴图飞行，命中才是绿色星粒/泥土爆。
   - 建议：① `STATUS_TEXTURES["nature"] = "res://assets/icons/verarc/thorn_vine_spell.png"`（16x16 绿藤，scale 1.6）；② 更贴"延伸藤蔓"语义：弹道改绿色飞刺（`verarc/poison_dagger.png`）+ 命中时调用 `FxManagerScript.spawn_ground_fx("vine", ...)`（工厂已存在 fx_manager.gd:1279，water M3 定身已在用），地面爬藤 1s。

3. **flash 爆炸视觉半径 bug**
   - 当前视觉：落点只爆一小点光（scale_mult 下限 0.45），实际命中半径 90px（失明+伤害）。
   - 原因：`projectile.gd:174` 在 `:178` 盲爆半径提升**之前**就 emit 了 `fx_explosion_scaled`（radius≈1）。
   - 建议：把 `EventBus.fx_explosion_scaled.emit` 移到盲爆半径修正之后（radius 提到 90 再 emit），视觉即与"强光闪击"匹配；光柱形态 height 118 也正好覆盖。

4. **frenzy 狂暴无狂暴视觉**
   - 当前视觉：施放瞬间黄色闪电爆（kind 传 lightning，spell_caster.gd:141）；3 秒狂暴期玩家无任何持续反馈（光环/变色/特效）。
   - 建议：① 施放改 `EventBus.fx_explosion.emit(pos, "buff")`（配方已存在：金色扩散环+星粒）；② 狂暴持续期给玩家挂持续光环：复用 fx_manager 的 `spawn_status_particles(parent, "buff")` 或 `_build_aura_rings` 风格程序化光环（挂 player，3s 后释放）；③ 可选：狂暴期玩家 modulate 泛红。

### P1（视觉存在但错位/缺失关键段）

5. **teleport 无起点视觉**
   - 当前视觉：玩家凭空消失→落点紫色漩涡爆（落点 ✅）。
   - 建议：`_cast_teleport` 瞬移前 `EventBus.fx_cast.emit(player.global_position, "void", aim)` + 残影（复制 player 精灵 tween 渐隐 0.2s），起点与终点都可见。

6. **mana_echo 无回响视觉 + 颜色错位**
   - 当前视觉：冰蓝爆（kind=ice），与核心元素 void/“回响余波”语义不符。
   - 建议：改 `fx_explosion.emit(pos, "void")`；再补一圈向外扩张的回响环（复用 explosion.tscn 的 Line2D 圆环，tween 到 3~4x 渐隐，0.6s），表现"余波重置全场冷却"。

7. **counterspell 反制爆炸是冰蓝色**
   - 当前视觉：冰晶+冰屑（kind=ice，spell_caster.gd:269），伤害却是 void。
   - 建议：改 `fx_explosion_scaled.emit(player.global_position, "void", r)`（紫色漩涡+内吸粒子，更贴"反制/吞没弹幕"）；弹幕销毁处可加每发小 fx_hit "void"。

8. **summon_bat 施法特效回退火色 + 召唤无落点视觉**
   - 当前视觉：`fx_cast` kind="summon" 无配方回退 fire 橙 muzzle（fx_manager CAST_RECIPES 无 summon）；蝙蝠凭空出现在随机偏移点。
   - 建议：① `_cast` 召唤分支改传 "buff"（或给 CAST_RECIPES 加 "summon" 配方：紫色符文粒）；② `_spawn_summon` 每个召唤点 `EventBus.fx_explosion.emit(pos, "void")` 小爆/光环标记落点。

9. **poison_cloud 无持续毒雾**
   - 当前视觉：一次性毒爆后场地无残留，与"释放毒雾持续造成伤害"（dot=true）不符；中毒反馈只挂在怪身上（绿色毒泡附着）。
   - 建议：落点 `FxManagerScript.spawn_ground_fx("poison", pos, 48, 2.0)`（与 poison_synergy.gd:315 同款用法），让毒雾在地面持续 2s，视觉与描述一致。

10. **blessing 无回血反馈**
    - 当前视觉：光柱+星粒 ✅，但 `GameState.heal(15)` 无 +15 绿色飘字/绿光（drain 路径有 fx_heal_text，blessing 路径没有）。
    - 建议：`_cast_blessing` 回血后补 `EventBus.fx_heal_text.emit(player.global_position, healed)` + 小 `fx_explosion.emit(pos,"heal")`。

### P2（辨识度/细节）

11. **delay 外壳悬停无提示**：`projectile.gd:102` delay 分支建议加 modulate 闪烁（0.8s 内 2~3 次脉冲）或脚下小光圈，避免"卡弹"错觉。
12. **bounce 反弹无反馈**：`_bounce_at`（projectile.gd:191）补 `EventBus.fx_hit.emit(clamped, _element)` 小粒子。
13. **ice_shard 锥尖方向**：`proj_ice.png` 锥尖朝下；建议旋转 90° 或换朝前锥形贴图（次要）。
14. **orbit 非旋风刃弹体不自旋**：可让 orbit 弹道 sprite 缓慢自转（视觉提示环绕运动，可选）。
15. **连带项：召唤系弹道全部是火球**：`summon.gd` 弹道 element="summon" 同样回退 fire 贴图（飞剑/法球/法师弹都是橙红火球）。建议 STATUS_TEXTURES 增 `"summon"` 映射（如 `proj_blade.png` 或按召唤类型分配），属同一 STATUS_TEXTURES 缺口。

## 5. 汇总统计

- 15 核心：✅ 5（fireball / ice_shard / lightning / whirl_blade / inferno），⚠️ 6（poison_cloud / summon_bat / teleport / counterspell / blessing / mana_echo），❌ 4（water_bolt / thorn_vine / flash / frenzy）。
- 10 外壳：✅ 6（rapid / spread / homing / pierce / burst / drain），⚠️ 4（bounce 无反弹反馈 / orbit 弹体不自旋 / delay 无待机提示 / split 分裂小弹继承弹体贴图缺口）。
- 问题总数：P0×4、P1×6、P2×5（含 1 项连带：召唤系弹道回退火球）。
- 共性根因 3 个：① `STATUS_TEXTURES` 映射不全（缺 water/nature/summon，回退火球）；② 特殊核心特效 kind 传错（counter/frenzy/mana_echo）；③ `_explode_at` 特效 emit 时机早于盲爆半径修正（flash）。
- 修复优先级：P0 四项全部可在 2 处文件内解决（projectile.gd STATUS_TEXTURES/`_explode_at`、spell_caster.gd 三个分支），无需新素材（verarc 16x16 图标直接可用，GroundPoison/GroundVine 工厂已存在）。
