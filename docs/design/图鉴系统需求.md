## 2. 数据字典（草案）

### collections.json（全局收集档案，user:// 持久化）

```json
{
  "version": 1,
  "items": ["attack_speed_potion", "vampire_fang", "..."],
  "spells": ["fireball:rapid", "ice_shard:spread", "..."],
  "enemies": ["slime", "bat", "slime_king", "..."],
  "bosses": ["slime_king", "tree_golem", "final_god", "..."]
}
```

字段契约：
- `items`：字符串数组，元素 = 物品 id（含装备/饰品/记忆，来源 items.json）
- `spells`：字符串数组，元素 = "核心id:外壳id"（外壳可为空 → "fireball:"）
- `enemies`：普通敌人 id 列表（来源 enemies.json enemies）
- `bosses`：Boss id 列表（来源 enemies.json bosses）
- 收集时机写入；重复获得不重复记录（去重）

## 3. UI 契约

- 主菜单：按钮"图鉴"（约 90×32），样式与"开始游戏"一致，位于"继续游戏"下方
- 图鉴界面：全屏 CanvasLayer；顶部标题"图鉴" + 4 个分类 tab（装备/法术/敌人/Boss）
- 网格：FlowContainer，格子 64×64（图标 48 + 名称 12px 底部）
- 已收集：图标 + 名称 + 稀有度描边（装备用物品稀有度；法术用核心稀有度；敌人/Boss 用灰/金描边）
- 未收集：`UiTheme.icon_texture` 压黑显示（modulate 黑色 40% 亮度），名称"？？？"
- 详情弹窗：点击已收集条目 → 居中 PanelContainer（与升级卡片同风格），显示完整描述与数值
- Esc / × 关闭返回主菜单

## 4. 验收标准

1. 新档（或清空收集档案）打开图鉴：全部条目为黑色剪影 + "？？？"，点击无详情
2. 一局内获得 ≥1 装备、≥1 法术、击杀 ≥1 敌人、击杀 1 Boss 后：图鉴对应条目彩色 + 可查看详情
3. 返回主菜单再进图鉴，收集状态保持；关闭浏览器重新打开仍保持（持久化）
4. 数值测试：collections.json schema 校验（test_curves.py 扩展）
5. 冒烟测试：图鉴场景可实例化、分类切换无报错
