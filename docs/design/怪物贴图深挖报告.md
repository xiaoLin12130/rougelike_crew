## 二、深挖过程与候选来源

### 2.1 全库扫描方法
- 用 PIL 遍历全部素材包：Pixel Crawler 2.11（角色/Mobs：Orc Crew、Skeleton Crew）、Retro-Lines-v3.4.3（Enemies/Bosses/Fireworks/Environment/Player）、sunny-land（atlas.json 命名帧）、Mana Seed、GandalfHardcore、Legacy-Fantasy High Forest（Boar/Bee/Snail）、Shikashi Icons v1/v2、VerArc Stash。
- 对 Retro-Lines 大图集逐图块做结构特征分析（覆盖度/宽高比/连通域数/HSV 直方图/透明度），再对候选图块逐像素 ASCII 渲染确认形状与配色。

### 2.2 各怪候选对比与最终选择

#### ghost 幽灵
- 候选 A（**采用**）：`Enemies.png` 第 2 行图块 (2,5)~(2,8) + (2,0)(2,1)，共 6 帧。圆头 + 锥形飘裙 + 波浪下摆 + 黄眼，帧间上下浮动（飘浮感）。这是图集中形状最好的小幽灵（旧图是第 8 行的"板状方鬼"，用户反馈不佳）。
- 候选 B：`Enemies.png` 第 8 行 (8,5)~(8,8) 经典幕布鬼（原色浅蓝灰 a192 半透明）——即旧图来源，形状方正，弃用。
- 候选 C：`Enemies.png` 第 5 行 (5,5)~(5,8) 黄眼红脚小幽灵——保留为备选。
- 处理：采用 (2,5)(2,7) 两帧（帧差 46px，上下飘动）；白体 FFF1E8 → 淡青白 D8F2F0 并降透明度至 α208（半透明感）；黄眼保留提亮。

#### imp 小恶魔
- 候选 A（**采用**）：`Enemies.png` 第 7 行 (7,5)~(7,8)+(7,10) 带双角骷髅（黄眼、尖牙、红鼻，5 帧含张嘴咬合）。全库唯一"有角 + 邪恶感"的恶魔形素材。
- 候选 B：`Enemies.png` 第 6 行 (6,0)~(6,11) 红翼飞行物——旧图来源（鸟形展翅，无角无恶感），弃用。
- 候选 C：Pixel Crawler Orc-Shaman / Skeleton-Mage（已被 cultist/specter 占用，避免重复）。
- 处理：采用 (7,5)(7,7) 两帧（帧差 87px = 咬合动画）；骨体 C5D6DB → 暗红 A02020，眼/齿 FFCF29 → 琥珀 FFB420，红 FF4242 → 亮红 FF2E2E。

#### crystal_sentry 水晶哨兵
- 候选 A（**采用**）：sunny-land `atlas.png` gem-1（15x13 多棱面宝石，含 4 段明暗 + 白高光，5 帧动画可扩展）。真实游戏素材，棱面感与发光感最强。
- 候选 B：`Enemies.png` 第 9/17/19/20 行 (x,5) 白色菱形轮廓（16x16，α192）——可用但平面感强。
- 候选 C：`Enemies.png` 第 12 行 (12,0)~(12,8) 灰红"水晶"——实为钥匙形状（旧图来源！旧 crystal_1 就是这把钥匙的 2x），弃用。
- 处理：gem-1 裁剪 (0,0,15,13)，紫色四段映射冰蓝（BB58CC→3E86C8、4C2562→16466E、E6AFF0→9EE0F8、FCFCFC→F0FFFF），4x NEAREST 放大到 60x52，居中于 64x64 画布（与旧图同画布，size=0.5 下屏幕尺寸不变）。

#### spider 毒蛛
- 候选 A（**采用**）：`Enemies.png` 第 20 行 (20,0)~(20,3) 方体蛛（四足、节肢花纹、红眼，4 帧）。全库唯一真实蜘蛛。
- 候选 B：Legacy-Fantasy Small Bee（虫形但非蜘蛛）、sunny-land eagle（鸟，已用于蝙蝠）——均不符。
- 旧图问题：旧 spider_1.png（64x32）实际是"两张蜘蛛并排"的拼图，显示为双蜘蛛；新图恢复单只。
- 处理：采用 (20,0)(20,3) 两帧；橙体 FF7918 → 毒绿 4CB020、绿 009323 → 深绿 006E18、黄 FFCF29 → 青柠 D8F020、红眼 FF4242 → 亮红 FF3030；2x NEAREST 至 32x32。

#### mimic_block 魔像方块
- 候选 A（**采用**）：`Enemies.png` 第 18 行 (18,5)~(18,8) 方块怪（白身 + 双眼 + 尖齿嘴 + 小脚 + 顶部触角，4 帧左右走位循环）。方块 + 牙齿 + 眼睛 + 陷阱感完全命中。
- 候选 B：sunny-land `atlas-props.png` face-block（32x32 紫石脸块）——可用但仅 1 帧、无齿，弃用。
- 旧图问题：旧 mimic_1 来自 (5,15)(5,16)(12,15)(12,16)——经逐块核实这些是**光标箭头**图块（D 区 UI 元素），所以旧图是实心矩形无脸无齿。
- 处理：采用 (18,5)(18,6)(18,7)(18,8) 四帧；白体 FFF1E8 → 金棕 F0C878、脸(眼齿) C5D6DB → 深棕黑 3A2010、棕 BE6E2B → 深木 7A4416、橙 FF7D00 → 亮金 FFA020；2x NEAREST 至 32x32。
