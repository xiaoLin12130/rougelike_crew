# 落雷误触发排查报告

- 排查日期：2026-08-11
- 项目：rougelike_crew（Godot 4.7.1）
- 排查方式：全量静态代码 + 数据审计（只读，未修改任何游戏代码）
- 用户反馈：未选择雷系技能时，场上仍会出现落雷

## 一、结论摘要

**误触发路径共 9 条，其中 7 条为「纯视觉误触发」（不造成伤害），1 条为「敌人阵营雷系真伤+视觉」，1 条为「升级选项未做元素过滤的诱导路径」。**

真正由玩家构筑驱动的雷系伤害路径（thunder_synergy 全部钩子、雷系法术、雷系法杖、雷云/雷核等）**全部有 thunder 构筑门控，不存在无门槛触发**。用户看到的「莫名其妙的落雷」几乎全部来自**与构筑无关的 lightning 特效复用**（高 DPS 爽感特效、切关特效、敌人/Boss 技能、拾取/防御/召唤特效），以及**升级三选一里雷系法术部件不受元素过滤**导致的误点。

按嫌疑程度排序：

| # | 触发路径 | 位置 | 构成误触发 | 是否造成伤害 |
|---|---------|------|-----------|-------------|
| 1 | 高 DPS 档位随机落雷（爽感粒子雨） | fx_manager.gd:356-361 | 是（无条件） | 否（纯视觉） |
| 2 | Boss 转阶段全屏雷爆+雷伤 | boss.gd:780-797 | 是（敌我混淆） | 是（对友军真伤） |

| 4 | 切关中心落雷 | game_root.gd:478 | 是（无条件） | 否（纯视觉） |
| 5 | 拾取任意法术部件闪雷 | item_pickup.gd:73 | 是（无条件） | 否（纯视觉） |
| 6 | 精英怪三连射/狙击手蓄力雷光 | enemy.gd:387/767 | 是（敌我混淆） | 否（视觉） |

## 二、雷系触发源全量清单（数据层）

### 2.1 data/items.json —— 雷系相关物品（23 件带 thunder/lightning tag）

统计口径：tag 含 thunder/lightning/chain/paralyze/electric/storm 的物品共 23 件（thunder_1~10 十件数值道具 + thunder_m1~m10 十件机制道具 + storm_cloud 雷云 + trinket_storm 雷核 + water_conduct 湿润导电）。另有 3 件名称含 storm/shock 但**不属于雷系**（crit_storm_eye 暴风眼、crit_crit_storm 暴击风暴、defense_counter_shock 反震，tag 均为 crit/defense）。

**能主动触发落雷的只有 8 件（全部需要玩家持有对应构筑）：**

| id | 行号 | 触发条件 | 门控 |
|----|------|---------|------|
| storm_cloud（雷云） | items.json:255 | 每 3s 落雷 1+⌊层/2⌋ 道 | `_stacks("storm_cloud") > 0` |
| thunder_m1（麻痹） | items.json:4411 | 雷击 6% 麻痹 1s | `_stacks("thunder_m1") > 0` |
| thunder_m2（雷暴） | items.json:4431 | 击杀 12% 范围落雷 | `_stacks("thunder_m2") > 0` |
| thunder_m3（静电积累） | items.json:4451 | 移动满充能放连锁电弧 | `_stacks("thunder_m3") > 0` |
| thunder_m5（导雷） | items.json:4491 | 每 3s 微型闪电链 | `_stacks("thunder_m5") > 0` |
| thunder_m8（超载线圈） | items.json:4551 | 同目标 3 次雷击后爆 | `_stacks("thunder_m8") > 0` |
| thunder_m9（雷云风暴） | items.json:4571 | 每 5s 随机落雷 | `_stacks("thunder_m9") > 0` |
| thunder_m10（高压电网） | items.json:4591 | 麻痹敌人死亡连锁电爆 | `_stacks("thunder_m10") > 0` |

**其余 15 件为数值/联动型，自身不触发落雷**：thunder_1（雷伤+10%/层）、thunder_2（链跳+1/2层）、thunder_3（链距+20px/层）、thunder_4（麻痹率+6%/层）、thunder_5（雷攻速）、thunder_6（递减）、thunder_7（精英优先）、thunder_8（雷冷却）、thunder_9（电荷叠乘）、thunder_10（雷暴击）、thunder_m4（过载）、thunder_m6（回响）、thunder_m7（致盲）、trinket_storm（雷核，仅翻倍已有触发）、water_conduct（水M4，仅对已有 lightning 元素伤害加成）。

### 2.2 data/spells.json —— 雷系法术

- 闪电核心（spells.json:30-39）：element=lightning、base_damage=18、chain=2。**唯一**的玩家雷系法术核心。获取途径：升级三选一法术部件 / 击杀掉落（spell_part 分支，当前 kill_drops 表未启用该掉落类型，实际仅升级三选一）。
- 外壳（shells）无任何 lightning 字段，不引入雷。

### 2.3 data/wands.json —— 雷系法杖（5 把）

surge_staff（:192）/ volt_staff（:211）/ storm_staff（:230）/ chain_staff（:250）/ thunder_staff（:269），均为固定池物品（稀有度加权随机上架），**不存在随机词缀系统**——「随机词缀带雷」的假设不成立。关键结论：法杖只提供 element_bonus 增伤与 shape_mods 形态，**不改变法术元素**（spell_caster.gd:346-350 元素取 core.element），即购买雷杖但用火球 = 火弹，不会凭空落雷；雷杖的雷伤加成只对雷系法术生效。

### 2.4 scripts/synergies/thunder_synergy.gd —— 钩子全量审计

- 注册（无条件，但全部回调有堆叠门控）：_ready() 注册 enemy_died/enemy_hit/projectile_hit/player_move（:63-67）
- `_on_projectile_hit`（:157-191）：element≠lightning 直接 return；M6/M1/M7/M8 均 `_stacks("thunder_mX") > 0` 门控
- `_on_enemy_hit`（:192-218）：`_stacks("thunder_m4") <= 0` 直接 return
- `_on_enemy_died`（:221-241）：M10/M2 均门控
- `_on_player_move`（:243-263）：`_stacks("thunder_m3") <= 0` return
- `_tick_conduit`（:266-282）M5 / `_tick_storm`（:284-309）M9 / `_tick_storm_cloud`（:311-336）storm_cloud：全部按对应 stack 门控
- `_bolt_dmg` 基础 18 雷伤仅由 thunder_1 层数放大（:352-355）

**结论：thunder_synergy 不存在无门槛触发**。任何落雷伤害都必须先持有对应 thunder_ 构筑。EventBus 钩子被无条件调用（SynergyRegistry.load_synergy_scripts 启动时加载全部 synergy 脚本，synergy_registry.gd:38-51），但每个回调内部都有 stack 守卫，未持有构筑时零副作用。

### 2.5 召唤物 / 装备被动

- summons.json：无任何 lightning 字段，召唤物本身不带雷。
- trinket_storm（雷核）：仅 `_trinket_storm_mult()` 翻倍 M2 概率/M9 数量（thunder_synergy.gd:340-347）+ mech_items.gd:54-55 对 lightning 元素伤害 +25%。**无 lightning 源时自身不触发**。
- mech_items.gd 其余逻辑（石肤/恐惧咒/霜心/熔岩护符）均非雷。
- 注意：trinket 掉落分支（game_root.gd:417-421 `_roll_drop` kind=trinket）当前为死代码（kill_drops 仅有 gold 一项，drops.json），trinket_storm 实际无法通过掉落获得。

### 2.6 敌人 / Boss 雷系技能（敌我混淆重灾区）

- enemies.json affix "lightning"（迅捷，:55-62）仅加移速/攻速/体型，**无雷系视觉无雷系伤害**。
- Boss 技能映射（boss.gd:406-457 分发，479-493 更新）：skeleton_king sweep → `_update_sweep`（:572，每 0.1s 沿扇形线发 lightning 爆，:587）；ancient_guardian beam → `_update_beam`（:704，:670）、shield_ring → `_cast_shield`（:668，:727）；final_god whirl_laser → `_update_whirl`（:716，:714）。
- **所有 Boss 转阶段** `_on_phase_up`（:770-801）：boss 位置+玩家位置+场地四角共 6 处 lightning 爆（:780-789），并对场上其他敌人造成 lightning 元素真伤（:797 `e.take_damage(shock, "lightning", false)`）。
- Boss 死亡双爆 fire+lightning（:846-847）。
- 精英怪 triple 三连射前摇 lightning（enemy.gd:387）、狙击手 sniper 蓄力 lightning（enemy.gd:767）。

## 三、误触发路径逐条分析（文件:行 / 触发条件 / 误触发判定 / 修复建议）

### 路径 1：高 DPS 档位随机落雷（最高嫌疑）
- 位置：scripts/fx/fx_manager.gd:356-361（_process 内爽感档位）
- 触发条件：`GameState.estimate_dps() >= 1500`（档位 3）时，每 2.5s 在随机屏幕位置 `EventBus.fx_explosion.emit(rand_pos, "lightning")`
- 误触发判定：**是，无条件**。KIND_RECIPES.lightning（fx_manager.gd:52-61）渲染为完整落雷（雷云团+闪电柱+落点火花），与玩家雷系法术视觉完全相同；任何高 DPS 构筑（火/剑/暴击/召唤）后期均可达 1500 DPS，与是否持有雷系构筑无关。这是「没选雷系却出现落雷」的最可能来源。另注意 :409-410 lightning 震屏随 lightning holdings 缩放（无雷时仍有小震屏）。
- 修复建议：加雷系门控 `if GameState.school_holdings().get("lightning", 0) > 0` 才发 lightning 特效；无雷系时档位 3 只发 gold（或换主流派色）。

### 路径 2：Boss 转阶段全屏雷爆 + 雷系真伤
- 位置：scripts/enemies/boss.gd:780-797
- 触发条件：任意 Boss 转阶段（hp 低于 phase 阈值）→ 玩家位置、Boss 位置、四角各发 lightning 爆 + 对场上其他敌人造成 20% max_hp 的 lightning 元素伤害
- 误触发判定：**是（敌我混淆 + 真伤）**。视觉上满屏落雷劈向玩家与四周，且雷系元素伤害是敌人阵营发出（经 enemy.gd:786 走 enemy_hit 钩子，若玩家持水M4 湿润导电还会吃到玩家雷系加成，见边界条目）；玩家无雷系构筑时极易误认为是自己的技能。
- 修复建议：转阶段视觉改金色/红色系（如 buff/fire）并区分敌我；:797 伤害元素改 fire/void 或保持 lightning 但视觉明确标注为 Boss 技能。

### 路径 3：Boss 雷系技能视觉（sweep/beam/shield/whirl）
- 位置：scripts/enemies/boss.gd:587（sweep）、:670（beam）、:714（whirl）、:727（shield）
- 触发条件：skeleton_king sweep（每 0.1s 沿扫射扇形发雷）、ancient_guardian beam/shield_ring、final_god whirl_laser 施放时
- 误触发判定：**是（敌我混淆）**。四技能全部复用玩家同款 lightning 视觉；尤其 final_god 的 whirl_laser 每 0.1s 连续发雷，观感=「场上不停落雷」。伤害经 player_hit 结算，视觉上却与玩家雷系法术无差别。
- 修复建议：敌人技能定义加专属视觉 kind（如 enemy_lightning 红色系/带敌意描边），或改现有 fire 系视觉；不动伤害逻辑。

### 路径 4：切关中心落雷
- 位置：scenes/game/game_root.gd:478
- 触发条件：每关清场后（非最终关）`EventBus.fx_explosion.emit(Vector2(320,180), "lightning")`
- 误触发判定：**是，无条件**。每次切关屏幕中心必劈一道雷，与构筑无关。
- 修复建议：换为当前主流派色（GameState._main_element）或固定用 fire/water；一行改动。

### 路径 5：拾取任意法术部件闪雷
- 位置：scripts/items/item_pickup.gd:73
- 触发条件：玩家拾取任何 spell_part 掉落（无论元素）→ lightning 爆
- 误触发判定：**是，无条件**。拾取火球/冰锥部件也会闪雷光。
- 修复建议：按部件核心元素取色（解析 payload core），或改中性色（如 heal/gold）。

### 路径 6：精英怪三连射 / 狙击手蓄力雷光
- 位置：scripts/enemies/enemy.gd:387（triple 技能）、:767（sniper 蓄力）
- 触发条件：精英怪施放 triple、狙击手（哥布林弓手等）蓄力狙击时
- 误触发判定：**是（敌我混淆）**。敌人蓄力/施法闪光与玩家落雷同款视觉。
- 修复建议：敌人蓄力视觉统一改红色/橙色系（与玩家元素色区分）。

### 路径 7：防御 M10 金身触发雷爆
- 位置：scripts/synergies/defense_synergy.gd:341
- 触发条件：持有防M10（金身）且血量<30% 触发 3s 无敌 → 玩家位置 lightning 爆
- 误触发判定：**是（跨流派视觉借用）**。纯防御/诅咒构筑无雷系时，残血触发会在玩家身上劈一道雷。
- 修复建议：改金色 buff 视觉（与 spell_caster 狂暴/回响同款做法：buff 系）。

### 路径 8：召唤物精英化雷爆
- 位置：scripts/synergies/summon_synergy.gd:215
- 触发条件：召唤物被升为精英（召M10/精英强化）→ lightning 爆
- 误触发判定：**是（跨流派视觉借用）**。召唤构筑无雷系时召唤物升级也闪雷。
- 修复建议：改金色/召唤色（如 heal/gold），或加 lightning holdings 门控。

### 路径 9：升级三选一雷系法术部件不受元素过滤（诱导路径）
- 位置：scripts/core/game_state.gd:207-276（roll_item_choices 的 N2 元素过滤 :222-228）+ :352-383（_make_spell_choice）
- 触发条件：升级三选一时，**物品**按「未持有元素不进入池」过滤（N2），但**法术部件选项无条件随机**，雷系闪电核心（spells.json:30）会在无任何雷系构筑时出现在三选一；玩家未细看卡片（如「迅捷·闪电」）点选后即获得雷系法术，随后自动落雷。
- 误触发判定：**是（诱导性误触发）**。与 N2 物品过滤规则不一致，是「技能出的莫名其妙」的另一大概率来源（选到没注意是雷系）。
- 修复建议：_make_spell_choice 同样按 holdings 过滤核心元素（未持有元素的核心不进入生成池）；或卡片显著标注元素色条/图标。

## 四、已排除的路径（确认不构成误触发）

1. **thunder_synergy 全部钩子**：4 个钩子 + 3 个周期 tick 全部有 `_stacks("thunder_mX")` / `_stacks("storm_cloud")` 门控（详见 2.4），无雷系构筑时零副作用；EventBus 无条件广播但回调全部守卫。
2. **雷系法术/法杖/物品掉落**：物品掉落仅 gold（drops.json kill_drops），精英只掉血包、Boss 只掉血包——不存在「随机掉雷系道具自动进包」路径；雷杖购买/雷系物品拾取均为玩家主动选择。
3. **随机词缀带雷**：wands.json 无词缀系统，不成立。
4. **召唤物带雷**：summons.json 无雷。
5. **敌人 lightning 词缀（迅捷）**：纯数值（移速/攻速/体型），无雷视觉无雷伤。
6. **水M8 暴雨 / 暴M10 暴击风暴 / 暴风眼**：暴雨用 water 视觉（water_synergy.gd:253）、暴击风暴用 fire 视觉（crit_synergy.gd:568）、暴风眼非雷 tag——均不产生落雷视觉。
7. **player_aura 雷云**：按 lightning holdings 档位（3/6/9）劈闪电（player_aura.gd:137-143），有持有数门控，属正常雷系反馈。
8. **水M4 湿润导电 / 雷核增伤**：仅对已存在的 lightning 元素伤害做加成，本身不产生落雷。

## 五、边界条目（低概率但值得注意）

- **Boss 转阶段雷伤可激活玩家雷系联动**：boss.gd:797 的 lightning 真伤经 enemy.gd:786 走 `enemy_hit` 钩子，若玩家同时持有水M4（湿润导电）且目标被减速，玩家的水雷联动会对非玩家雷伤的目标补发 lightning 额外伤害（water_synergy.gd:190-196）——「敌人雷伤触发玩家雷系机制」的间接路径。建议 enemy_hit 上下文增加来源标记（attacker/owner），玩家联动仅响应玩家来源。
- **trinket 掉落分支为死代码**：game_root.gd:417-421 的 trinket 掉落若未来启用，雷核（trinket_storm）可能随机进入无雷构筑（虽不主动触发，但会翻倍 M2/M9）。建议启用时按 holdings 过滤。
