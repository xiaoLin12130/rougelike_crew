## 1. BUG 清单（只记录，不修复）

### P0-1 弹道核心直击 0 伤害（本次体验最大问题）

- **位置**：`scripts/combat/projectile.gd` `_scan_contact()` → `_explode_at()`
- **根因**：`_scan_contact` 接触敌人时先 `_hit_enemies[id]=true`，再调用 `_explode_at`；爆炸循环中同一敌人被 `_hit_enemies.has(id)` 跳过 → **接触目标吃不到爆炸伤害**。
- **实测证据**（experience_probe 引擎内）：火球 d=40 / d=200 / d=260（含 homing 外壳）全部 0 伤害；爆炸点距目标仅 12px（溅射圈 26px）仍无伤害。
- **波及核心**：所有 `speed>0` 且 `aoe>0` 的弹道核——火球(aoe18)/冰锥(aoe14)/水弹(aoe12)/藤蔓(aoe26) 及穿透/弹射/分裂外壳组合。
- **影响**：Boss 战只有瞬发核（闪电/火柱/毒雾/传送/闪光）与环绕旋风刃能输出 → 阵亡局史莱姆王战有效 DPS 仅 2.6-11（设计 25+），骷髅王战最低 4.0/s（磨 135s 后阵亡）。
- **修复方向**（供开发参考）：`_explode_at` 前不预写 `_hit_enemies`，或在爆炸循环中对接触目标单独结算。

### P1-2 瞬发核心近身必脱靶（闪光/毒雾/火柱/闪电落点固定）

- **根因**：`speed=0` 的核心在 `_physics_process` 中直接 `global_position = spawn + dir × range` 固定落点爆炸，落点不落在目标身上。
- **实测命中窗口**（目标在正前方 d 处，含体型 8px）：
  - flash：range=200，盲半径兜底 90 → **[102, 298]px**；d=80 实测脱靶、d=200 命中+致盲 2s、d=320 脱靶
  - poison_cloud：range=200 aoe=48 → **[144, 256]px**；d=100 脱靶、d=200 命中
  - inferno：range=220 aoe=64 → **[148, 292]px**；d=100 脱靶、d=220 命中
  - lightning：range=260 aoe=26，但 chain=2 链跳搜索半径 160px 兜底 → **实测 150~320px 全部命中**（有效范围远超静态窗口）
- **对用户反馈“闪光不自动追踪”的结论**：闪光发射方向确实指向最近敌人（`_aim_dir` 自动索敌），但因为是瞬发、落点固定在 200px 处，不会“追踪”目标位置；近身敌人（<102px）时闪光在目标身后爆开，视觉上表现为“放空炮”。建议：瞬发核改为落点在目标当前位置，或弹道化。

### P1-3 “追踪”外壳（homing）对瞬发核心完全无效

- homing 只在弹道 `_move_step` 生效；flash/lightning/poison_cloud/inferno 装“追踪”外壳零收益（实测 flash+homing d=80 仍脱靶）。
- 玩家在“追踪·闪光”“追踪·闪电”上浪费构筑位 → 建议数据层禁止或提示无效组合。

### P2-5 XP 曲线文档漂移

- 实际公式：`xp_to_next(L) = 40 + 30×(L-1) + 5×(L-1)²`（balance.json base=40，GameState 实现一致）
- 但：PROGRESS.md 记 `50+30(L-1)+5(L-1)²`；数值设计.md 记 `60+35×L`；GameState 注释写“L1≈50(约6只怪)”——三处文档全部与实现不符（实际 L1=40，约 5-7 只 slime/bat）。

### P3-6 其余小项

- `drops.boss_drops.gold_mult=5` 代码无引用：Boss 金币按 enemies.json 的 gold 发放（slime_king 40 → final_god 300），“金币×5”表意未落地（当前实现可视为 Boss 固定高额金币）。

### 3.2 节奏评估

- 前 5 级（前两关）每级间隔 15-25s：与设计“前两波 ~20s/级、6 只怪/级”基本吻合，开局节奏 OK。

- 建议：第 1 关三选一保底给 1 个“瞬发/环绕”类核心，或在 8 杀保底道具处增加第 1 关必掉 1 个攻击性构筑。

## 4. 构筑流派难度分析

### 4.1 获取概率权重（F9 元素加权公式 + N2 筛选 + 非主流保底，6000 次三选一模拟）

- 公式：`w = 稀有度权重 × min(1 + 0.02 × 持有件数 × 关卡系数, 1.6)`，关卡系数 = 1+0.25×(L-1)；上限 +60%。
- N2 筛选：未持有的元素流派构筑（带元素 tag）不进入选项池（开局仅 火/剑/通用 可出）。
- 保底：存在非主流元素池时，三选一至少 1 个来自非主流元素（防单流派锁死）。

| 场景 | 法术部件占比 | 道具元素分布（模拟） |
|---|---|---|
| 开局（火1+剑1） | 33.3%（每轮必含 1） | 剑 55.1% / 通用 39.4% / 火 5.4% |
| L1 已持火×3 | 33.3% | 通用 86.7% / 火 13.3% |
| L3 已持火5+剑2 | 33.3% | 剑 55.2% / 通用 38.8% / 火 6.0% |
| L5 已持毒×8 | 33.3% | 通用 79.3% / 毒 20.7% |

- 解读：单元素持有的元素道具出现率仅 5-21%（被 260+ 件通用池稀释），**靠“持有多件同元素”堆权重收效有限**（+2%/件/关，6 件才 +12-24%，上限 +60% 需 30 件）；真正的流派定向来自 N2 筛选的“排除法”+ 非主流保底，而非正向加权。
- **难度结论**：随缘流最容易（任意 3 选即战力）；定向流派（火/毒/雷等）需要刻意只拿该元素，且每轮只有 1 个法术部件槽位 → 成型慢、方差大。实测 11 局 bot 从未成型单一流派（见 4.2），印证“按稀有度+DPS 打分”的通用流是当前最优解。

### 4.2 实测升级三选一选择分布（11 局共 ~240 次升级）

| 类别 | 出现次数 | 说明 |
|---|---|---|
| 法术核心 水弹 | 16 | bot 打分 DPS 优先 + 通用流，法术部件三选一必含 1 个 |
| 召唤蝙蝠 | 14 | 召唤核保底分 45+，bot 常选 |
| 火球/冰锥/旋风刃 | 各 10 | |
| 闪电/火柱 | 各 8 | 瞬发核实战价值最高但 bot 打分一般 |
| 传送 | 6 | |
| 藤蔓/毒雾 | 4/2 | |
| 闪光/圣光/反制/狂暴/回响 | **0** | bot 评分 -60（低伤/辅助核），从不出现在胜局构筑 |
| 道具 TOP | 火攻药×8、灰烬使者×6、雷云/火源晶石/水泽/处刑/狂化/攻速药水等×4 | 攻速/元素增伤/暴击类优先 |

- 胜局构筑示例：R7 传送×2+水弹×4+旋风刃×2+火柱×2；R10 藤蔓×4+冰锥×4+毒雾×2+闪电×2+召唤×2；R11 召唤×4+旋风刃×2+水弹×2+火柱×4。共同点：**大量瞬发/环绕/召唤核**（绕开 P0 直击 0 伤），未形成任何单一元素流派。
- 难度排序（实测）：通用随缘流（易）> 召唤流（中，召唤物不吃直击 bug）> 瞬发核流（中上，需要选到闪电/火柱/传送）> 元素定向流（难，加权弱+法术部件槽少）> 弹道核流（**最难，P0 bug 下单体 DPS 归零**）。

### 5.2 用户疑问解答：技能格子右下角角标含义

- **法术（技能）格子**：右下角金色小字 = **外壳名首字**（连发→“连”、齐射→“齐”、追踪→“追”、穿透→“穿”、弹射→“弹”、环绕→“环”、爆发→“爆”、延时→“延”、分裂→“分”、吸血→“吸”）；无外壳则不显示。它不是层数/等级/序号（2026-08-10 已从“外壳序号”改为首字，见 `build_panel.gd _refresh_grid`）。
- **物品格子**：右下角白色数字 = **持有堆叠数 ×N**（数量 >1 才显示，`_icon_slot`）。
- 左上角“联动”绿字 = 该构筑所属流派持有 ≥2 件已激活联动。

## 6. 改进建议（按优先级）

1. **修复 P0 弹道核直击 0 伤**（预计修复后 Boss 战 DPS 翻倍以上，胜率可回到 60%+）。
2. **瞬发核落点改为目标当前位置**（或加 150-200px 短弹道）：解决闪光/毒雾/火柱近身放空、用户“不追踪”感知。
3. **第 1 关保底瞬发/环绕类核心**：三选一或 8 杀保底处保证“闪电/火柱/传送/旋风刃”之一，压平 27% 胜率方差。
4. **homing 外壳与瞬发核组合禁用或提示**（当前零收益构筑位）。
5. **统一数值口径**：balance.json loop_hp/loop_dmg 与 GameState 硬编码对齐（表值或代码二选一）；xp.base 文档三处对齐为 40；补 gold_mult 引用或删除。
6. **元素加权调强**：+2%/件/关 上限 60% 太弱（30 件才封顶），建议 +5%/件/关 或 保底权重 +0.5× 持有元素池，让定向流派可玩。
7. **升级三选一法术部件权重偏向未持有元素/流派缺口**，否则 bot 与玩家都会陷入“全拿 DPS 通用件”的同质构筑。
