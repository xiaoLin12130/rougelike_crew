## 9. 新发现 BUG（只记录不修）

### P2-1 荆棘甲反弹在 0 层时仍按 base 40% 生效，近身局触发物理回调内分裂报错（本轮新发现）
- **现象**：召唤流近身局（6b 复现运行）出现 16 次 `ERROR: Can't change this state while flushing queries.
  Use call_deferred() or set_deferred() to change monitoring state instead.`（非致命，但污染日志）。
- **证据链**（引擎 backtrace）：`enemy_bullet.gd:28 _on_body` → `game_root.gd:407`（荆棘甲反弹
  `attacker.take_damage`）→ `enemy.gd:791 take_damage` → `:801 _take_raw` → `:835 _die`
  （分裂史莱姆 `add_child` 生成分裂体）——在物理冲刷期改碰撞体状态。
- **根因**：① `GameState.item_value` 的 linear 曲线在 n=0 层时返回 `base`（`base*(1+k*max(n-1,0))`，n=0 时 = base），
  `thorn_reflect` 无持有层数也按 0.40 反弹 40%——疑似 0 层应为 0 的边界缺陷（契约"第 1 层 = base"未处理 0 层）；
  ② 分裂史莱姆死亡时 `add_child` 未用 `call_deferred`，在反弹-击杀回调链（物理冲刷期）内生成新碰撞体。
- **触发条件**：玩家被敌人弹幕命中且最近敌人为分裂型史莱姆且反弹伤害足以击杀——召唤流近身局命中率最高；
  常规局未出现（本轮 6 局中仅召唤复现局出现 16 次）。
- **影响**：非致命；日志噪音 + 反弹伤害使玩家隐性减伤（疑似平衡偏差，待确认设计意图）。

### P3-2 法杖商店格式化缺参数（第 2 轮 P2-3 遗留，未修）
- `wand_shop.gd:179 _refresh`：`String formatting error: not enough arguments for format string`，
  本轮常规 5 局每局 1-4 次（R1×1/R2×3/R3×2/R4×4/R5×4），商店功能正常仅报错噪音；召唤局 R6 商店开启 4 次未触发
  （取决于刷出的法杖字段组合）。

### P3-3 败局共性：低 DPS 构筑的 Boss 战磨血（观察项，非代码缺陷）
- R1（炎魔 16.1/s）、R6（9-17/s）均死于 Boss 战血线被磨空；胜局首关 Boss 均 ≤10s。与 R2 结论一致：
  构筑随机性下伤害核心缺失是败局主因，可作平衡性参考（如 Boss 战时间软上限或保底构筑权重）。

### 方法学记录（非游戏 BUG）：测试包装场景的 current_scene 陷阱
- 调查期间用包装场景包裹 game_root 会令 `get_tree().current_scene` 指向包装根，autoplay 的覆盖层查找全部落空
  → 升级/商店流程丢失、关卡卡死（两轮复现，均为此工具问题，游戏本体无此问题）。
- 已改为"主场景根直接挂 game_root.gd + 首个子节点先改写构筑"（`.tmp/summon_modifier.gd`）规避。

## 10. 结论与建议

1. **P0 召唤光环崩溃修复验证通过**：专项 600 帧回归全绿 + 真实召唤流长局（光环 tier1 全程生效、召唤物批量生灭）
   484s 无崩溃、正常结算；第 2 轮 R1 必崩局面不再复现。
2. **通关率维持 80%**（4/5，与 R2 持平，显著高于 R1 的 27%）；胜局耗时 501-636s，经济上限大幅抬升（8996 金）。
3. **视觉 P0 + 图标 38 条替换 + 三选一改回 + Boss 数字层级 + 火地重入修复全部无回归**：6 项回归测试全绿，实战无相关报错。
4. **建议**：① 修复 item_value linear 0 层返回 base 的边界（荆棘甲 0 层 40% 反弹），并将分裂史莱姆
   `add_child` 改为 deferred（消除物理冲刷期报错）；② 处理 wand_shop.gd:179 格式化缺参（遗留 P2）；
   ③ 平衡向：为低 DPS 构筑提供 Boss 战保底（如首关 Boss 战时长软上限），减少"磨死"败局。
