## 0. 项目目标

- 在 `H:\rougelike_crew` 用 **Godot 4.7.1** 开发一款像素风 Roguelike 小游戏

**特效原则（铁律）**：绝不用静态贴图冒充特效。所有特效按优先级实现：
1. **程序化特效**：GPUParticles2D/CPUParticles2D + 自定义 shader + Tween（免费、体积小、可调参）
2. **素材粒子帧**：Space Shooter / Sunny Land 自带的逐帧特效序列

## 2. 四款游戏构筑分析

> 完整报告见 `docs/research/game-build-analysis.md`（基于 Steam 官方商店页与 Fandom wiki 数据）。

### 2.1 结论摘要（四款游戏构筑机制）

| 游戏 | 构筑方式 | 组合规则 | 爽点 |
|---|---|---|---|
| 魔法工艺 | **法杖网格**：法术=核心×外壳，按序排列 | 顺序即输出循环（连发/齐射/环绕/追踪）；+80 遗物 | 自创法术循环一波清屏、发现感 |
| 吸血鬼幸存者 | 6 武器 + 被动直接装备 | 武器满级+被动满级=**进化质变**；升级三选一 | 全屏割草、进化瞬间 |
| 雨中冒险 | 道具无限叠加 + 1 主动装备位 | 叠加三曲线：线性（+15%/层）/指数（1-0.85ⁿ）/阈值 | 堆叠数值爆炸、循环变强 |
| 梦之形 | **技能(主动)+记忆/精粹(被动)** 双轨 | 8 英雄×150+ 记忆精粹自由组合；9 清醒梦变量 | 技能连招、构筑协同爆发 |

### 2.2 融合方案要点（详见第 3 节）

- **五轨构筑槽位**：法杖网格（魔法工艺）+ 武器槽（VS/RoR）+ 技能槽+记忆（梦之形）+ 饰品槽（梦之形/VS）+ 道具无限叠加（RoR）
- **叠加曲线数据驱动**：每个道具声明线性/指数/阈值三类曲线
- **进化合成**：武器满级+饰品满级→质变
- **6 条流派路线**：元素弹幕/召唤/近战狂暴/冰冻控制/暴击暴伤/诅咒传染
- **爽的四层机制**：数值爆炸 + 全屏粒子视觉轰炸 + 进化质变慢动作 + "决战 Boss or 继续刷"抉择张力

## 3. 构筑系统融合方案（草案，待分析完成后细化）

吸收四款游戏特点的框架（**待确认**）：

- **武器槽（直接装备）**：类 VS/雨中冒险，武器自动攻击或主动施放，同类叠加
- **法术网格（排序释放）**：类魔法工艺，多个法术核心+外壳按排列顺序形成连招序列（连发/齐射/环绕/追踪），**顺序即构筑**
- **技能 + 饰品槽**：类梦之形，技能提供主动能力，饰品提供被动联动
- **道具叠加曲线**：类雨中冒险，线性/指数/阈值三类曲线，构筑成型后数值爆炸
- **时间压力**：类雨中冒险，随关卡轮次敌人强度指数上升，逼玩家"成型或暴毙"
- **流派路线**（6 条差异化路线）：元素弹幕流 / 召唤流 / 近战狂暴流 / 冰冻控制流 / 暴击暴伤流 / 诅咒传染流（详见研究报告中 5.3 表格，每条都有成型检测+进化+专属爽点）

## 3.1 冗余设计原则（DEMO 期就位，防返工）

1. **数据驱动**：道具/法术/敌人/关卡/掉落全部 JSON 表驱动，改数值不动代码；
2. **模块解耦**：玩家/敌人/特效/UI 通过 EventBus 信号通信，禁止节点间直接互扒字段；
3. **输入抽象**：`InputRouter` 统一键盘/虚拟摇杆 → 后续微信端零改战斗代码；
4. **存档抽象**：`SaveStore` 接口（File/Web/Wx 三实现），DEMO 先落 File；
5. **素材可替换**：所有精灵通过 Resource 引用，换皮只换文件不改逻辑；
6. **渲染器兼容**：gl_compatibility 渲染器（Web 唯一选择，2D 无功能损失）；
7. **分包意识**：音效/特效小文件独立目录，微信分包时直接拆。

## 6. 数值设计框架（基于已入库书籍）

数值设计参考书已入库 RAG（`--src books` 可查）：
- **《Game Balance Concepts》Ian Schreiber 全 10 章**（数值关系、成本曲线、概率与随机、进程与节奏、度量与统计）

数值设计原则（草案）：
1. **构筑成长曲线**：单件道具线性 +10%，同类堆叠第 3 件起转阈值/指数曲线，保证"成型质变"
2. **敌人成长**：以"轮次"为单位，血量 ×1.25/轮、伤害 ×1.15/轮、数量 ×1.2/轮（参考雨中冒险的时间压力），玩家成长必须跑赢曲线才有爽感
3. **TTK 原则**：小怪 1-3 击，精英 5-8 击，Boss 30-60 秒；数值膨胀后允许秒杀（爽点）
4. **概率与随机**：掉落保底（坏运气保护）、构筑三选一权重修正
5. **数据驱动**：所有数值进 JSON 表，便于调参回归；测试 Agent 用手算用例验证

> 详细数值表与公式见 `docs/design/数值设计.md`；数值测试见 `tools/tests/`。
