> 日期：2026-08-08　撰写：主 Agent（基于 Steam 官方商店页 + Fandom wiki 数据 + RAG 知识库）

## 0. 结论速览

## 1. 《魔法工艺》Magicraft（Steam 2103140，俯视角法术构筑肉鸽）

### 1.1 构筑机制
- **法术 = 核心(Core) + 外壳(Shell)**：核心决定基础效果（火球/冰锥/闪电/召唤等），外壳是修饰器（连发、齐射、追踪、穿透、弹射、分裂、环绕、延时……）。
- **法杖 = 法术容器**：每把法杖有独特词条/属性（射速、蓝耗、槽位数等），全游戏 100 把。
- **网格排列，顺序即构筑**：法术在法杖网格上按顺序排列，施放时**按排列顺序循环发射**。排序方式直接改变释放行为：
  - 把「连发」放在「火球」前 → 火球连发；
  - 把「环绕」放首位 → 后续法术环绕自身旋转；
  - 把「分裂」置于序列中间 → 从该位置起法术分裂。
  - 因此**同一个法术集合，不同排列 = 完全不同的输出循环**，这是它构筑深度的核心来源。
- **遗物（80 种）**：被动强化道具，可叠加，部分改变角色外观；商店、铁匠锻造房、谜题关提供额外获取。
- 9 款初始角色套装；5 大章节 + 古神（最终 Boss）。

### 1.2 构筑深度来源
1. 核心×外壳的组合空间（官方宣称"开发者也无法穷尽"）；
2. 排列顺序带来的**输出循环设计**（类似卡牌游戏的牌序，但实时化）；
3. 蓝量/冷却的资源约束迫使玩家在"爆发循环"与"续航"间取舍；
4. 遗物与法术的跨系统联动（如"冰系法术+冰冻遗物→碎冰增伤"）。

### 1.3 爽点来源
- 成型后的法术循环**一波清屏**的视觉冲击；
- "我发明了一套别人没见过的构筑"的**发现/创造感**；
- 法杖+遗物+法术三者协同后的**乘法级数值膨胀**。

## 2. 《吸血鬼幸存者》Vampire Survivors（自动攻击割草肉鸽）

### 2.1 构筑机制
- **6 武器槽 + 被动道具**：武器自动索敌攻击，无需瞄准；被动道具直接装备（全被动道具可同时持有，无槽位上限）。
- **升级三选一**：升级时从"武器/被动/钱袋/恢复"加权随机池中三选一（稀有度决定权重）；已有武器再次选择 = 升级（1→8 级，每级加伤/加速/加弹）。
- **进化（Evolution）**：武器满 8 级 + 指定被动满级 → 合成台/宝箱触发**进化**，质变为更强武器（如 鞭子+空心之心→血泪；魔法杖+空书→圣杖）。新版本还有 Union（双武器合体）与 Gift。
- **时间压力**：一局 30 分钟，敌人数量与属性随时间**指数上升**，30:00 死神降临。
- **局外成长**：金币购买永久强化（meta progression）。

### 2.2 构筑深度来源
1. 6 武器 × 武器被动搭配的**进化配方**（配方知识即构筑）；
2. 武器间联动（范围武器+攻速+持续时间组合成"全屏绞肉机"）；
3. 稀有度权重系统制造"筑池管理"（Ban/选择武器影响后续掉落概率）；
4. 移动走位 vs 站桩输出的风险取舍。

### 2.3 爽点来源
- **全屏伤害数字与粒子**的视觉轰炸（本质是"自动化的正反馈"）；
- **进化瞬间的质变**（屏幕效果立刻升级）；
- 割草：1 分钟清 100+ 怪的密度 + 经验磁铁吸爆屏；
- 30 分钟冲刺（死神来之前的 DPS 军备竞赛）。

## 3. 《雨中冒险》Risk of Rain / Returns / 2（道具堆叠肉鸽）

### 3.1 构筑机制
- **道具直接拾取、同名无限叠加**：没有槽位概念，捡到即生效，同类道具堆叠。
- **叠加曲线三类型**（RoR2 数据实证）：
  - 线性加算：Soldier's Syringe +15% 攻速/层；
  - 独立概率（指数）：Tougher Times 免伤 = 1 - 0.85^n（第 n 层）；57 Leaf Clover 好运 = 1-(1-p)^(n+1)；
  - 阈值/封顶型：部分冷却减免道具按层递减并封顶。
- **装备位（Equipment）**：唯一主动技能位（导弹/传送/回血等，CD 型）。
- **时间压力**：敌人强度 = f(时间, 关卡)，难度系数随时间持续增长；道具必须跑赢曲线。
- **循环结构**（RoR1/Returns 模式，即本项目要模仿的）：5 个关卡打完后，可选择**决战最终 Boss**（Providence）或**返回第一关继续循环**，循环后敌人与掉落数值整体抬升。
- 稀有度体系：白(常见)/绿(罕见)/红(传说)/黄(Boss)/蓝(月石)/紫(虚空)。

### 3.2 构筑深度来源
1. **曲线数学本身**：同一道具不同层数收益曲线不同（线性/指数/阈值），玩家需要理解"第几层收益拐点"；
2. 稀有度与场景互动（祭坛、箱子、Boss 掉落）；
3. 生存压力驱动下"攻防平衡"的取舍；
4. 角色差异 × 道具通用性的组合。

### 3.3 爽点来源
- **数值膨胀的直观体现**：攻速 300%、暴击 100%、一枪秒 Boss 的军备竞赛；
- 循环刷取的正反馈：每关都在变强，敌人追不上你；
- "打最终 Boss 还是继续变强"的**抉择张力**（失败惩罚 vs 贪刀收益）。

## 4. 《梦之形》（Steam 2444750，MOBA 式动作肉鸽）

### 4.1 构筑机制（官方资料）
- **8 位旅行者（英雄）**：各自拥有独特战斗机制与技能组（近战切入/精准技能/大范围/辅助），玩家围绕英雄风格构筑。
- **150+ 记忆与精粹**：
  - 「记忆」≈ 技能相关强化（可挂到技能上改变行为，类似"技能符文"）；
  - 「精粹」≈ 被动饰品（全局属性/机制改动）；
  - 自由组合成"阵容"，构筑方向 = 技能强化路径 + 被动骨架。
- **9 种「清醒梦」玩法变量**（类似难度 modifier，改变每局规则）。
- 4 种难度、8 大世界、Boss 战；最多 4 人联机协同（构筑互补产生单人不存在的连招）。

### 4.2 构筑深度来源
1. **技能(主动) × 饰品(被动) 双轨**：主动路径决定"怎么打"，被动骨架决定"数值底子"；
2. 英雄机制差异放大构筑差异（同一套饰品在不同英雄身上玩法完全不同）；
3. 随机三选一（每局不同路径）+ 清醒梦变量强制换打法。

### 4.3 爽点来源
- MOBA 式技能连招的手感（位移+控制+爆发一套连）；
- 技能强化后"技能进化"的直观变化（范围/段数/机制改变）；
- 多人协同的组合爆发（本项目单人，可降级为"召唤物协同"）。

## 5. 融合方案：本项目构筑系统设计（待用户确认）

### 5.1 槽位模型（五轨构筑）

| 槽位 | 来源借鉴 | 说明 |
|---|---|---|
| 法杖网格（5 格） | 魔法工艺 | 法术核心×外壳按序排列，**顺序 = 输出循环**；每关掉法术核心/外壳碎片 |
| 武器槽（1-2） | VS / RoR | 直接装备的主动武器（自动索敌 or 手动），自带成长 |
| 技能槽（1） | 梦之形 | 主动技能（位移/控制/爆发），可挂「记忆」强化 |
| 饰品槽（3） | 梦之形 / VS 被动 | 全局被动，提供流派骨架 |
| 道具背包（无限叠加） | RoR | 同名叠加，三类曲线（线性/指数/阈值） |

### 5.2 组合规则
1. **法术 = 核心 + 外壳**（魔法工艺式），核心 × 外壳组合空间为目标构筑多样性的第一来源；
2. **进化合成**（VS 式）：指定武器满级 + 指定饰品满级 → 质变进化（每流派 1-2 条进化路线）；
3. **叠加曲线**（RoR 式）：每个道具声明自己的曲线类型，数值表驱动；
4. **记忆强化**（梦之形式）：技能可挂 1 个记忆（改变行为而非纯数值）；
5. **流派检测器**：系统检测构筑倾向（弹幕数/攻速/暴击/召唤数/DEBUFF 数），命中阈值时给隐藏联动（触发"构筑成型"的正反馈）。

### 5.3 首发流派路线（6 条，每条都有成型检测 + 进化 + 专属爽点）

| 流派 | 核心词条 | 成型爽点 |
|---|---|---|
| ① 元素弹幕流 | 齐射/弹射/追踪 + 攻速 + 暴击 | 全屏弹幕海 + 数字雨 |
| ② 召唤物流 | 召唤核心 + 数量叠加 + 光环饰品 | 军团压境，自己逛街 |
| ③ 近战狂暴流 | 近战武器 + 攻速 + 吸血 + 范围 | 割草无双 + 回血永动机 |
| ④ 冰冻控制流 | 冰核心 + 冻结/碎冰联动 | 全场静止 + 碎冰连锁爆炸 |
| ⑤ 暴击暴伤流 | 暴击率指数曲线 + 暴伤 + 处决 | 单发数字从百到百万 |
| ⑥ 诅咒/DEBUFF 流 | 毒/诅咒叠层 + 增伤联动 + 扩散 | 一跳伤害链条全屏传染 |

### 5.4 "爽"的四层机制（必须全部落地）
1. **数值爆炸**：RoR 式指数曲线，构筑成型后 DPS 每关 ×2~3；
2. **视觉轰炸**：程序化粒子全屏化 + 伤害数字放大镜（数字越大字号越大/带震屏）；
3. **质变瞬间**：进化合成/流派成型触发全屏闪光 + 慢动作 0.3s（time_scale 缓动）+ 音效；
4. **抉择张力**：5 关后"决战 Boss or 继续刷"（雨中冒险式），数值按轮次膨胀。

### 5.5 与"微信小游戏"的适配考量
- 构筑 UI 简化：法杖网格 ≤5 格拖拽、三选一卡片、道具列表——均适合触屏；
- 操作：虚拟摇杆 + 攻击自动 + 技能按钮（俯视角方案最合适）；
- 特效全部程序化（粒子/shader）→ 包体小、可压缩，适配小游戏分包。
